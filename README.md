# Dynamic-industry

## blastsim — 발파 진동 · 파쇄 · 비산 통합 해석 프로그램

폭약 종류 · 장약량 · 저항선 · 공간격 · 지발시차 · 전색 · 자유면 조건을 입력하면,
**원거리 진동은 FDM 으로, 근거리 파쇄·비산은 DEM 으로** 나누어 해석하고
결과를 보고서 · 그래프 · 영상으로 만든다.

```
                    ┌─ FDM (fdm.py) ──→ PPV · 주파수 · 규제검토 · 지표 진동 등고선/영상
암반 · 폭약 · 패턴 ─┤
자유면 · 전색       └─ DEM (frag.py) ─→ 파쇄입도 · 이동/적재 · 비산거리 · 파쇄 영상
```

두 방법을 나눈 이유는 각자 잘하는 일이 다르기 때문이다. 진동 전파는 균질 연속체의
탄성파 문제라 FDM 이 격자당 정확도와 속도에서 유리하고, 파쇄·비산은 불연속·대변형
문제라 DEM 이 아니면 풀 수 없다.

## 2. FDM — 원거리 진동

엇갈림 격자(staggered grid) 속도-응력 정식화, 공간 4차 / 시간 2차
(Virieux 1986, Levander 1988).

```
sxx,syy,szz : (i,   j,   k  )        vx : (i+½, j,   k  )
sxy         : (i+½, j+½, k  )        vy : (i,   j+½, k  )
sxz         : (i+½, j,   k+½)        vz : (i,   j,   k+½)
syz         : (i,   j+½, k+½)
```

**격자형 DEM(lattice.py) 대비 이점**

| 항목 | 격자 DEM | FDM |
|---|---|---|
| 파장당 요소수 | 10 | 6 (3D 격자수 1/8) |
| 임계 dt | `d/(√2·Vp)` | `h/(√3·(9/8+1/24)·Vp)` — 약 2.5배 |
| 포아송비 | **0.25 고정** (Cauchy 관계) | **자유 지정** |

**자유면 — 진공 정식화.** 암반 밖 셀에 `λ = μ = ρ = 0` 을 주면 그 경계가 자유면이
된다. 응력 미러링보다 정확도는 낮지만 **2자유면 벤치처럼 꺾인 경계를 그대로 표현**할
수 있어 이 문제에 적합하다. 정확도 보완을 위해 Moczo 방식 유효매질 평균(전단계수
조화평균, 밀도 산술평균)을 쓴다.

**감쇠 — Kelvin-Voigt.** `σ = C:ε + β·C:ε̇`, `ζ(f) = π·f·β`. 저주파는 거의 통과하고
고주파일수록 강하게 감쇠하므로, 실제 암반의 거동과 격자 상한 부근 수치잡음을 함께
처리한다. 점성항이 임계 dt 를 줄이는 분까지 계산에 반영한다.

**흡수경계** — Cerjan 스펀지 (자유면 제외).

### 검증 — Rayleigh 파 속도

반무한체 자유면 위 Rayleigh 파는 속도가 정확히 알려져 있고 비분산이므로,
**탄성계수와 자유면 구현을 동시에** 검증할 수 있다. 이론값은 Rayleigh 방정식
`x⁶ − 8x⁴ + (24−16k²)x² + 16(k²−1) = 0` 의 근 ξ(ν)·Vs 이다.

| 측점 거리 / 파장 | 측정 VR | 이론 VR | 오차 |
|---|---|---|---|
| 1.30 | 2732 | 2767 | −1.27 % |
| 2.60 | 2734 | 2767 | −1.20 % |
| **5.20** | **2765** | **2767** | **−0.08 %** |
| 5.86 | 2713 | 2767 | −1.94 % |

ν = 0.20 / 0.25 / 0.30 에서 VR/Vs 가 이론(0.9110 / 0.9194 / 0.9274)대로 변하는 것도
확인했다.

> 처음에는 −4 % 가 나왔고 격자를 2배 조밀하게 해도 −3.9 % 로 **수렴하지 않았다**.
> 이산화 오차라면 줄어야 하므로 추적한 결과, 모델 편의가 아니라 해석영역이 좁아서
> 생긴 근거리·경계 오염이었다. 영역을 넓히자 −1 % 대로 떨어졌다. 그래서 이 프로그램은
> 해석영역을 최원 계측거리의 0.6배 이상으로 **자동 확장**한다.

## 3. DEM — 근거리 파쇄 · 비산

발파공 주변 수 m 를 구형 입자로 채우고 중심력 본드로 결합한다.
`k = 0.4·E·d` 이면 격자가 정확히 등방 탄성체가 된다(아래 4절 유도).

* **본드** : 인장변형률이 `σt/E` 를 넘으면 파괴 → 균열
* **접촉** : 본드가 끊긴 뒤 구-구 접촉. 선형 스프링 + 점성(반발계수) + Coulomb 마찰
* **중력** : 비산 탄도와 적재 형상을 지배
* **자유면 2면** : 상부면(z=0) + 벤치면(x=face_x). 굴착선 아래는 하부 소단으로 구속
* **시간적분 2단계** : 본드가 살아 있는 초기 수십 ms 는 dt 를 작게, 대부분 끊긴
  뒤에는 훨씬 무른 계가 되므로 dt 를 크게

### 충격파와 가스를 분리한다

발파 파괴는 두 단계로 일어나며, 둘을 섞으면 안 된다.

| 단계 | 시간 | 하는 일 | 모델 |
|---|---|---|---|
| 충격파 | µs~ms | 방사균열 · 자유면 반사 인장파에 의한 박리 → **파쇄** | 등가공동 압력감쇠식 (진동해석과 동일) |
| 가스팽창 | ms~10ms | 균열에 침투해 단열팽창하며 파쇄암을 밀어냄 → **이동·비산** | `P = P₀(V₀/V)^γ` |

**가스는 반드시 폭약 화학에너지로 정박해야 한다.** 등가공동 압력을 그대로 써서
`P₀V₀/(γ−1)` 로 일을 계산하면 폭약이 가진 에너지의 6배가 나온다 — 등가공동 반경이
실제 천공경보다 훨씬 크기 때문이다. 그래서 거꾸로 간다:

```
E_gas = η_gas · W · Q          (Q = 폭발열, η_gas ≈ 0.15~0.30)
P₀    = E_gas · (γ − 1) / V₀
```

정박 결과 저항선 이동속도가 **15.7 m/s** 로 나와 실무값 10~30 m/s 범위에 든다.

### 완전 전색

전색 판정은 가스 추력과 전색재 마찰을 정적으로 비교하면 **항상 '분출'로 나온다**
(추력이 마찰의 수십 배다). 실제로 전색이 기능하는 것은 정적 강도가 아니라 관성과
시간 때문이므로, 판정은 실무에서 검증된 기하 기준으로 하고 물리량은 참고치로 함께
보인다.

| 조건 | 판정 |
|---|---|
| T/B ≥ 0.7 **그리고** T/천공경 ≥ 20 | 양호 — 완전 전색 기능 |
| T/B ≥ 0.5 그리고 T/천공경 ≥ 15 | 보통 — 공구 비산·폭풍압 주의 |
| 그 미만 | 불량 — 전색 분출 우려 |

## 4. DEM 격자가 정확히 등방 탄성체가 되는 이유

단순입방 격자에 1차 이웃(축방향 6개)과 2차 이웃(면대각 12개)을 중심력 본드로
연결한다. 강성텐서는 affine 가정에서

```
C_ijkl = (1/V) Σ_bond  k · L² · n_i n_j n_k n_l         (V = d³)
```

| 본드 | 개수/입자 | 길이 | C11 | C12 | C44 |
|---|---|---|---|---|---|
| 1차 이웃 | 3 | d | k₁/d | 0 | 0 |
| 2차 이웃 | 6 | √2·d | 2k₂/d | k₂/d | k₂/d |

합계 `C11 = (k₁+2k₂)/d`, `C12 = C44 = k₂/d` 이고, 등방조건 `C44 = (C11−C12)/2` 가
**k₁ = k₂ 에서 자동으로 만족**된다. 이때 `λ = μ = k/d` 이므로

```
ν = 0.25 (고정),  E = 2.5·k/d  →  k = 0.4·E·d
Vp = √(3k/(ρd)),  Vs = √(k/(ρd)),  Vp/Vs = √3
```

동역학행렬 고유값으로 검증한 결과 장파장 극한에서 오차 **0.00 %**, [100]/[110]/[111]
세 방향이 모두 동일(등방성 확인), 파장당 10요소에서도 −1.6 %.

## 5. 검증 (`python tests/test_blastsim.py`)

**FDM** — 탄성계수(ν 자유), 자유면·2자유면 형상, 점성 포함 임계 dt, Rayleigh 파 속도

**DEM 격자** — 분산관계(0.00 %), 등방성, 수치분산, 배위수 18, 탄성상수 해석해 복원

**DEM 파쇄** — 초기 평형(본드력·접촉력 정확히 0), 2자유면 경계, 가스 에너지 수지,
공벽 속도 임피던스 한계, 전색 판정, 파쇄체 연결성분 · 질량보존

**공통** — 폭굉압, 압력이력, 지발당 최대장약량, 폭원 격자무관성 및 합력 0,
Rayleigh 감쇠 계수, 환산거리식 왕복, 보정 선형성, 퇴화 입력 무크래시

### 근거리 DEM 을 안정화하기까지 잡은 것들

수치해석에서 발산은 대개 물리 모델이 아니라 정식화의 허점에서 온다.
에너지 수지(운동에너지 vs 폭원이 한 일)를 직접 재는 것이 가장 빠른 진단이었다.

| 증상 | 원인 | 수정 |
|---|---|---|
| 5,000 m/s 로 발산 | 공벽 입자에 압력만 가하고 주변 암반 임피던스 저항이 없음 | Lysmer 방사감쇠 `ρVp·A·v` 추가 → 벽면속도가 `P/(ρVp)` 로 묶임 |
| 여전히 발산 | 충격파 하중이 **팽창하는** 공동 면적을 사용 → 입자가 날아갈수록 힘이 커지는 양의 되먹임 | 충격파는 고정 면적, 가스만 팽창 면적 |
| 본드 파괴 순간 폭발 | 교란 배치에서 접촉 기준거리를 일률적으로 2r 로 둠 → **초기부터 21 % 의 쌍이 겹침** | 원래 본드 쌍은 자기 L0 를 기준으로 |
| 연쇄 파괴로 발산 | 끊어진 2차 이웃 본드(L0 ≈ 1.41 d > 2r)가 **닿지도 않은 입자 사이에 54 MN 유령 반발력** 생성. 전체 본드의 79 % 가 해당 | 기준거리를 `min(L0, 2r)` 로 |
| 한 스텝에 2 m/s 씩 튐 | 방사감쇠 완화시간 `m/c` 가 dt 의 4.5배뿐인데 양해법 | 반경방향 성분을 **반음해**로 정확히 풂 |
| 근접부가 인공 강체가 되어 암반을 찢음 | 진동 모델의 '탄성코어 보호'를 파쇄 모델에 그대로 적용 — 목적이 정반대다 | 파쇄 모델에서는 근접부도 파괴 허용 |
| **여전히 발산** | 접촉 법선 점성항의 **부호가 반대** (`+c·vn`). `vn > 0` 은 멀어지는 중이므로 분리할 때 반발력이 커져 **충돌마다 에너지 주입** | `−c·vn` 으로 수정 |

마지막 부호 하나가 결정적이었다. 수정 후 43 ms 전 구간에서:

| t [ms] | KE [MJ] | 폭원 일 [MJ] | vmax [m/s] | 파괴 본드 |
|---|---|---|---|---|
| 5.4 | 5.79 | 9.17 | 18.4 | 9,781 |
| 16.3 | 4.72 | 8.09 | 15.9 | 11,948 |
| 27.1 | 7.25 | 15.11 | 15.6 | 14,710 |
| 43.4 | 5.31 | 17.86 | 14.9 | 17,614 |

운동에너지가 항상 폭원이 한 일보다 작고(차이는 파괴·마찰·경계에서 소산), 최대
입자속도가 **15~19 m/s** 로 실무 저항선 이동속도 범위에 머문다.

## 7. 한계 — 반드시 읽을 것

**테스트버전이다.** 패턴 변경의 상대적 효과를 비교하는 도구이지, 보정 없이 절대값을
예측하는 도구가 아니다.

### 7.1 절대 진동값은 반드시 보정해야 한다

무보정 해석 PPV 는 국내 설계 경험식 대비 **약 1/10** 로 나온다. 원인은 격자 해상도다.
폭원의 방사 속도스펙트럼은 `1/(2π·td) ~ 1/(2π·tr)` 구간에서 평탄한데(에멀젼 40~531 Hz),
격자가 감당하는 상한은 `Vs/(6·h)` 뿐이다.

| 폭약 | 폭원 평탄대역 | 150 Hz 초과 에너지 |
|---|---|---|
| ANFO | 27~318 Hz | 77 % |
| 에멀젼 | 40~531 Hz | **87 %** |
| 함수폭약 | 53~796 Hz | 93 % |

`--calibrate` (기본 켜짐)가 경험식에 맞춰 폭원 효율 η 를 자동 보정한다. 모델이 폭원
세기에 **정확히 선형**임을 테스트로 검증했으므로 배수 적용은 재해석과 동일하다.
**감쇠지수 n 과 패턴 변경의 상대효과는 보정과 무관하게 유효하다.**

### 7.2 탁월주파수는 과대평가된다

해석값은 격자 해상한계 부근에 붙지만 실제 원거리 계측은 보통 10~80 Hz 다. 절리
산란감쇠와 자유면 이완이 균질 탄성 모델에 없기 때문이다. 보고서가 자동 경고하며,
`--damp-band` 상한을 낮춰 산란감쇠를 근사할 수 있다. **규제 검토는 PPV 기준으로 하라.**

### 7.3 파쇄 입도는 DEM 이 아니라 Kuz-Ram 이 준다

**본드망의 연결성분으로 파쇄체를 세면 안 된다.** 이는 물리가 아니라 *본드 퍼콜레이션*
문제이기 때문이다. 배위수 12~16 격자에서 본드를 무작위로 제거해 보면:

| 본드 파괴율 | 클러스터 수 | 최대 클러스터 비율 |
|---|---|---|
| 30 % | 2 | 100 % |
| **44 %** | **1** | **100 %** |
| 70 % | 42 | 99.3 % |
| 85 % | 557 | 88.7 % |
| 90 % | 1,477 | 57.9 % |
| 95 % | 3,406 | 1.5 % |

실제 해석에서 본드 파괴율은 40~50 % 수준인데, 그 구간에서는 **전체가 여전히 한 덩어리**다.
그래서 연결성분이 주는 X50 은 5~10 m 같은 무의미한 값이 된다 (실무값은 0.2~0.5 m).

따라서 이 프로그램은 역할을 나눈다.

* **DEM 이 주는 것** : 본드 파괴율(손상도), 균열 분포, 이동속도, 비산 궤적, 적재 형상
* **Kuz-Ram 이 주는 것** : 파쇄 입도 X50 · X80 · 균등지수 n

```
X50 [cm] = A · K^(-0.8) · Q^(1/6) · (115/RWS)^(19/30)
n        = (2.2 − 14B/D) · √((1+S/B)/2) · (1 − W/B) · (L/H)
```

암반계수 A 는 UCS 로부터 7(연암)~13(경암)으로 환산한다. 검증 예:

| 조건 | 비장약량 | X50 | X80 | 과대석(>1 m) |
|---|---|---|---|---|
| 사암 B2.5 S3.0 H8 | 0.57 kg/m³ | 0.27 m | 0.50 m | 1.6 % |
| 화강암 B3.0 S3.5 H10 | 0.41 kg/m³ | 0.52 m | 1.00 m | 19.9 % |
| 화강암 B4.0 S4.6 H12 | 0.23 kg/m³ | 0.86 m | 1.82 m | 44.1 % |

보고서는 두 값을 모두 보이되, 본드 파괴율이 90 % 미만이면 DEM 연결성분 값에
**"신뢰할 수 없음"** 을 명시한다.

### 7.4 저항선 이탈이 과소평가된다

실제 벤치발파는 저항선 전체가 한 덩어리로 자유면 쪽으로 밀려나간다. 이 모델에서는
저항선의 일부만 떨어져 나간다.

| 항목 | 해석값 |
|---|---|
| 저항선 영역 평균 이동거리 | 1.54 m |
| 1 m 이상 이동한 비율 | 40 % |
| 자유면 밖으로 나간 비율 | 29 % |
| 최대 이동거리 | 10.5 m |
| 최대 입자속도 | 12.9 m/s |

**속도는 맞고(실무 10~30 m/s), 움직이는 부분의 이동거리도 맞지만, 움직이는 비율이
작다.** 원인은 발파공 열을 따라 형성되는 분리면이 이 해상도에서 완전히 형성되지
않기 때문이다. 공간격 3.5 m 가 입자 지름의 6배뿐이라 공 사이 균열면이 성기게
표현된다. 중심력 본드가 인장 파괴만 다루는 것도 겹친다.

따라서 **이동·적재 결과는 정성적으로 보고, 정량값이 필요하면 실측과 대조**해야 한다.
비산 속도와 도달거리는 움직이는 입자를 기준으로 하므로 상대적으로 신뢰도가 높다.

### 7.5 그 밖의 파쇄 해석 한계

* 입자 지름이 곧 **최소 파쇄체 크기**다(기본 28~60 cm). 세립부가 중요하면 입자를
  줄여야 하고 계산량이 급증한다.
* 본드는 **인장 파괴만** 다룬다(중심력 본드라 전단 저항이 없다). 발파의 지배 기구가
  인장 균열이므로 실용상 타당하지만, 전단 파괴가 중요한 문제에는 맞지 않는다.
* 입자에 **회전 자유도가 없다.** 마찰을 입자 중심에 걸므로 각운동량이 보존되지 않는다.
  적재 형상이 실제보다 다소 무질서할 수 있다.
* 무작위 교란을 주었지만 기본 배치가 규칙격자라 **파쇄체 형상에 격자 흔적**이 남는다.
* 비산거리는 최적 사출각(45°) 가정의 탄도 계산이라 **보수적(안전측)** 이다.
  공기저항을 무시하므로 소립 비산체는 과대평가된다.

### 7.6 그 밖의 가정

* 암반은 **균질 등방 연속체**. 절리·층리·단층과 그로 인한 감쇠·굴절·채널링 없음.
  실제 현장 진동 산포의 상당 부분이 여기서 나온다.
* **지반증폭·지형효과 없음** (표토층, 계곡·능선).
* **정적 응력장(지중응력) 미고려**. 진동은 그 위의 미소 섭동으로 다룬다.
* FDM 재료는 **균질**(단일 암종). 층상 지반은 지원하지 않는다.

### 권장 사용법

1. 시험발파 1회로 실측 PPV 를 얻어 η 를 고정한다.
2. 저항선·공간격·지발당 장약량·시차·전색을 바꿔가며 **상대 비교**로 최적화한다.
3. 최종 확인은 반드시 실측으로 한다.

경험식(환산거리식)을 대체하는 도구가 아니라, 경험식이 답하지 못하는 것 — 지발 시차
간섭, 자유면 방향성, 3성분 분포, 지표 등고선, 파쇄입도, 비산 위험거리 — 을 채우는
도구로 쓰는 것이 맞다.
