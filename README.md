# Dynamic-industry

## blastdem — 암발파 진동전파 3D DEM 해석 프로그램

폭약 종류 · 장약량 · 저항선 · 공간격 · 지발시차를 입력해, 발파진동이 암반을 통해
전파되는 과정을 **3차원 개별요소법(DEM)** 으로 해석하고 임의 위치의 PPV(최대입자속도)와
주파수를 산출한다. 결과는 국내 발파진동 규제기준 및 환산거리 경험식과 자동 비교된다.

```
암반 물성 ─┐
폭약 물성 ─┼─→ 3D DEM 격자 ─→ 등가공동 폭원 ─→ 시간적분 ─→ PPV / 주파수 / 규제검토
발파 패턴 ─┘
```

## 1. 빠른 시작

```bash
pip install -r requirements.txt

# 사용 가능한 암종/폭약/경험식 목록
python -m blastdem --list

# 화강암 벤치에서 에멀젼 2열x5공 발파, 30~120 m 진동 해석
python -m blastdem --rock granite --explosive emulsion \
    --burden 3.0 --spacing 3.5 --bench 10 --rows 2 --cols 5 \
    --distances 30 50 80 120 --out output

# 폭원 효율을 경험식에 자동 보정 (절대 진폭이 필요할 때 — 6.1절 필독)
python -m blastdem ... --calibrate --law kr_mean

# 예제 스크립트
python examples/01_bench_blast.py        # 전체 보고서 + 그림 7종
python examples/02_compare_explosives.py # 폭약 종류별 진동 비교
python examples/03_pattern_study.py      # 저항선·공간격·지발시차 파라미터 스터디

# 검증 테스트
python tests/test_blastdem.py
```

Python API:

```python
from blastdem import *

exp = get_explosive("emulsion")
pattern = BlastPattern(exp, burden=3.0, spacing=3.5, bench_height=10.0,
                       hole_dia=0.076, n_rows=2, n_cols=5,
                       delay_hole=0.025, delay_row=0.065)
pts, names = line_array((3, 0), (1, 0), [30, 50, 80, 120])

sim = BlastSimulation(rock=get_rock("granite"), explosive=exp, pattern=pattern,
                      sensor_points=pts, sensor_names=names).run()

sim.apply_calibration("kr_mean")        # 또는 factor=실측PPV/해석PPV
print(sim.report())
sim.save_figures("output")

print(sim.pattern.max_charge_per_delay) # 지발당 최대장약량 W [kg]
print(sim.fitted_law())                 # 해석으로 추정한 현장 K, n
```

## 2. 이론 배경

### 2.1 DEM 격자 — 왜 정확히 등방 탄성체가 되는가

단순입방 격자에 **1차 이웃(축방향 6개)** 과 **2차 이웃(면대각 12개)** 을 중심력 본드로
연결한다. 강성텐서는 affine 가정 하에

```
C_ijkl = (1/V) Σ_bond  k · L² · n_i n_j n_k n_l         (V = d³)
```

| 본드 | 개수/입자 | 길이 | C11 | C12 | C44 |
|---|---|---|---|---|---|
| 1차 이웃 | 3 | d | k₁/d | 0 | 0 |
| 2차 이웃 | 6 | √2·d | 2k₂/d | k₂/d | k₂/d |

합계 `C11 = (k₁+2k₂)/d`, `C12 = C44 = k₂/d` 이고, 등방조건 `C44 = (C11−C12)/2` 는
**k₁ = k₂ 에서 자동으로 만족**된다. 이때

```
λ = μ = k/d      →  ν = 0.25 (고정),  E = 2.5·k/d   →   k = 0.4·E·d
Vp = √(3k/(ρd)),  Vs = √(k/(ρd)),   Vp/Vs = √3
```

**한계**: 중심력 본드만 쓰므로 Cauchy 관계에 의해 포아송비가 0.25 로 고정된다.
대부분의 암반이 0.20~0.30 이므로 실용상 문제없지만, ν 가 중요한 문제에는
전단(비중심력) 본드 추가가 필요하다.

### 2.2 폭원 — 등가공동(equivalent cavity) 모델

천공경은 76 mm 인데 진동전파 해석 격자는 1~2 m 다. 공벽을 직접 이산화하려면
입자가 10¹² 개 필요해 불가능하므로, **탄성 거동이 시작되는 반경에 등가 압력**을 가한다.

```
폭굉압      Pd = ρe·VOD² / (1+γ)                    γ ≈ 3
공내압      Pb = 0.5·Pd·(dc/dh)^2.6                 디커플링 보정
파쇄대      r_h → r_c (≈4·r_h) :  P ∝ r^(−2)
탄성역      r_c → r_eq         :  P ∝ r^(−1)
등가압력    P_eq = η · Pb · (r_h/r_c)² · (r_c/r_eq)
```

`α_elastic = 1` 이므로 단위길이당 총 반경력 `P_eq·2πr_eq` 가 **격자간격에 무관**하다.
즉 격자를 바꿔도 폭원이 주는 임펄스가 보존된다 (`test_source_mesh_independence` 로 검증).

`η` 는 에너지 전달효율(가스 누출, 전색 불량, 파쇄 소산)로, **시험발파 실측치로 보정하는
계수**다. `sim.calibration_factor()` 가 목표 경험식에 맞추는 배수를 계산해 준다.

### 2.3 감쇠 — 강성비례 항이 왜 필수인가

Rayleigh 감쇠 `C = αM + βK`, `ζ(f) = α/(2ω) + βω/2` 를 두 기준주파수에서 목표
감쇠비에 맞춘다. 질량비례(α) 항만 쓰면 `ζ ∝ 1/ω` 라 **저주파를 더 감쇠**시켜
실제 암반과 반대로 거동하고, 격자가 해상하지 못하는 고주파 수치잡음도 남는다.
강성비례(β) 항이 이 둘을 함께 처리한다.

### 2.4 경계조건

- 상단 z=0: 자유면 (Rayleigh 파 생성)
- 나머지 5면: Lysmer-Kuhlemeyer 점성 흡수경계 `f = −(ρVp·A)v_n − (ρVs·A)v_t`

측방 반폭이 부족하면 파가 경계에 스치듯 입사해 흡수율이 급감하고, 반사파가
직접파에 실려 **기하감쇠가 과소평가**된다. 이를 막기 위해 해석영역을 최원 계측거리의
0.6배 이상으로 자동 확장한다.

- PPV 절대값은 2.5배 격자범위에서 ±25 % 변동한다.

### 그 외 검증 항목

- 탄성상수 해석해 복원 (`C44 = (C11−C12)/2`, `ν = 0.25`, `E` 역산)
- 내부 입자 배위수 18 (1차 6 + 2차 12)
- 폭굉압 `ρVOD²/4`, 디커플링 감압, 압력이력 정규화
- 지발당 최대장약량 (동시기폭 → 총장약량, 지발 → 공당 장약량)
- 폭원의 격자무관성 및 합력 0 (강체이동 방지)
- Rayleigh 계수가 두 기준주파수에서 목표 감쇠비 정확히 만족
- 환산거리식 왕복(허용장약량 ↔ 안전거리) 및 회귀 복원

## 5. 데이터베이스

**암종** (`--rock`): 화강암 · 편마암 · 석회암 · 사암 · 셰일 · 안산암 · 풍화암
현장 탄성파탐사 결과가 있으면 `--vp` 로 직접 지정하는 편이 정확하다.

**폭약** (`--explosive`): 초유폭약(ANFO) · 중유폭약 · 에멀젼 · 함수폭약 · 정밀폭약 ·
미진동 파쇄약 · 슬러리

**발파진동 허용기준** (PPV): 가축 1.0 / 문화재·정밀기기 2.0 / 주택·아파트 5.0 /
상가 10.0 / 철근콘크리트 40.0 mm/s

## 6. 한계 — 반드시 읽을 것

이 프로그램은 **패턴 변경의 상대적 효과를 비교하는 도구**이지, 보정 없이 절대 진동값을
예측하는 도구가 아니다. 아래 1~2번은 이 방법론의 근본 한계이므로 반드시 이해하고 써야 한다.

### 1. 절대 진폭은 반드시 보정해야 한다 (η)

무보정 상태에서 해석 PPV 는 국내 설계 경험식 대비 **약 1/10 수준**으로 나온다.
원인은 격자 해상도다. 폭원의 방사 속도스펙트럼은 `1/(2π·td) ~ 1/(2π·tr)` 구간에서
평탄한데(에멀젼 40~531 Hz), 격자가 감당하는 상한은 `Vs/(10·d)` (d=2 m 이면 150 Hz)뿐이다.

| 폭약 | 폭원 평탄대역 | 150 Hz 초과 에너지 |
|---|---|---|
| ANFO | 27~318 Hz | 77 % |
| 에멀젼 | 40~531 Hz | **87 %** |
| 함수폭약 | 53~796 Hz | 93 % |
| 미진동 파쇄약 | 16~133 Hz | 51 % |

즉 **폭원 에너지의 대부분이 격자가 실어나를 수 없는 대역에 있다.** 여기에 공벽 수십 mm
스케일의 파쇄·가스침투·자유면 이완 같은 비탄성 결합과정까지 더해져, 절대 진폭은
1차 원리로 예측되지 않는다. 이것은 이 프로그램만의 문제가 아니라 발파진동 수치해석
전반의 상황이며, 그래서 실무 모델은 모두 현장 보정을 쓴다.

```bash
python -m blastdem ... --calibrate          # 경험식에 자동 보정
```
```python
eta = sim.apply_calibration("kr_mean")      # 또는 실측값으로
sim.apply_calibration(factor=측정PPV/해석PPV)
```
보정은 정당하다 — 모델이 폭원 세기에 **정확히 선형**임을 `test_calibration_linearity`
가 검증한다. 그리고 **감쇠지수 n 과 패턴 변경의 상대효과는 보정과 무관하게 유효**하다.

### 2. 탁월주파수는 과대평가된다

해석 탁월주파수는 격자 해상한계 부근(150~220 Hz)에 붙는 반면, 실제 원거리 계측값은
보통 10~80 Hz 다. 원인은 두 가지이며 둘 다 균질 연속체 가정의 한계다.

- **절리·불연속면에 의한 산란감쇠 미반영.** 실제 암반은 고주파를 훨씬 빨리 잃는다.
  `--damp-band 10 60` 처럼 감쇠 상한을 낮추면 근사할 수 있으나 물리적 모사는 아니다.
- **자유면 이완·암반 이동 미반영.** 원거리 저주파 에너지의 상당 부분은 파쇄암 이동이라는
  대변형 과정에서 나오는데, 이 모델은 미소변형 탄성이라 이를 만들지 못한다.

보고서는 탁월주파수가 격자 한계에 근접하면 자동으로 경고한다. **주파수 값은 참고용으로만
쓰고, 규제 검토는 PPV 기준으로 하라.**

### 3. 포아송비가 0.25 로 고정된다 (2.1절)

### 4. 그 밖의 가정

- **암반은 균질 등방 연속체로 가정**한다. 절리·층리·단층 등 불연속면과 그로 인한
   파의 감쇠·굴절·채널링은 반영되지 않는다. 실제 현장 진동 산포의 상당 부분이
   여기서 나온다.

- **파쇄·비산은 모사하지 않는다.** 폭원 근방 비탄성 영역은 등가공동 압력감쇠식으로
   치환되고, 그 안쪽은 탄성코어로 보호되어 본드가 파괴되지 않는다. 파쇄도(fragmentation)
   예측이 목적이라면 다른 모델링이 필요하다.

- **지반증폭·지형효과 없음.** 표토층, 계곡·능선 지형에 의한 증폭은 고려되지 않는다.

- **정적 응력장(지중응력·중력) 미고려.** 진동은 그 위의 미소 섭동으로 다룬다.

### 권장 사용법

1. 시험발파 1회로 실측 PPV 를 얻고 `apply_calibration(factor=...)` 로 η 를 고정한다.
2. 저항선 · 공간격 · 지발당 장약량 · 시차를 바꿔가며 **상대 비교**로 패턴을 최적화한다.
3. 최종 확인은 반드시 실측으로 한다.

경험식(환산거리식)을 대체하는 도구가 아니라, 경험식이 답하지 못하는 것 — 지발 시차의
간섭, 자유면 방향성, 계측점별 3성분 분포, 지표 진동 등고선 — 을 채우는 도구로 쓰는 것이
맞다.
