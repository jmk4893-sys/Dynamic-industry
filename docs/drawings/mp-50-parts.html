제작도의 상세 패널 B–Q 16매를 한 장씩 펼친 것이다. 왼쪽은 치수를 기입한 2D 정투상도, 오른쪽은 같은 부품을 돌려 볼 수 있는 3D 다. 3D 는 단면으로 살두께를, 치수로 도면값을 그대로 보여준다. 조립도는 mp-50-3d.html 를 볼 것.

도면집 주기

  1. 2D 와 3D 는 같은 치수에서 나온다. 두 그림 모두 제작도 MP-50-P0-001 의 표기값을 코드 상수로 두고 그린 것이라, 상수를 고치면 2D 치수선과 3D 형상이 함께 움직인다. 눈으로 맞춘 그림이 아니다.
  2. 상세 시트는 도면 표기값을 그대로 그린다. 조립도 (mp-50-3d.html)는 조립이 성립하도록 일부 치수를 바꿔 그렸지만, 이 도면집은 상세 패널에 적힌 값을 그대로 쓴다. 두 값이 다른 시트에는 지적 표시를 붙이고 조립도에서 쓴 값을 함께 적었다.
  3. 3D 단면은 부품 축을 지나는 평면으로 자른다. 살두께(동체 t3, 커버 t5, 콘 t3, 배플 t2)와 보어·나사부를 보기 위한 것이며, 2D 의 A-A 단면과 같은 위치다.
  4. 선 굵기는 KS A ISO 128 을 따랐다. 외형선 : 숨은선 : 치수·중심선 = 1 : 0.5 : 0.25. 중심선은 일점쇄선, 숨은선은 파선이다.
  5. 제작·검사 기준은 조립도와 같다. 치수 공차 ±0.5 ~ ±2 mm, 용접 TIG(내부 연마·비드 제거), 압력시험 0.2 MPa × 30 min, 탱크 내면 Ra ≤0.8 µm, 조립 토크 M8 20 N·m / M10 40 N·m.

조립·분해도는 docs/drawings/mp-50-3d.html, 상류 분리설비는 docs/drawings/pv-delamination-3d.html, 하류 Ag 회수 부선 설비는 docs/drawings/ag-flotation-3d.html 참조.
