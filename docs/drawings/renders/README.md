# 플랜트 전경 렌더

`pv-recycling-miniapp.html` (DD-R4) 의 3D 씬을 조립(시뮬레이션) 모드에서 그대로 찍은 것이다.
손으로 그린 그림이 아니라 미니앱과 같은 지오메트리·재질·조명을 쓰므로, 미니앱이 바뀌면 이 그림도
다시 뽑아야 한다.

| 파일 | 시점 | 크기 |
|---|---|---|
| `plant-view-top.png` | 평면 — 거의 수직(85°) 하향 | 2604 × 900 |
| `plant-view-side-a.png` | 측면 A — +z 에서 −z 를 봄. 투입부가 왼쪽 | 2604 × 659 |
| `plant-view-side-b.png` | 측면 B — −z 에서 +z 를 봄. 측면 A 의 반대편 | 2604 × 659 |

습식부 데크는 밝은 회색 강재 그레이팅이다. 이전 판에서는 `material.frame`(metalness 0.76 · 환경맵 없음)
이라 평면에서 L≈15 의 검은 판으로 잡혀 그 위 장비를 눌렀다. 지금은 L≈160 으로, 스튜디오 배경(L≈114)
보다 밝고 중간톤 장비가 그 위에서 읽힌다.

## 촬영 기준

설비 실범위 (지반·그리드 제외) **33.66 × 9.00 m · 높이 6.15 m**
— x −11.70…21.95 / y −0.65…5.50 / z −3.40…5.60.

| 시점 | yaw | pitch | distance |
|---|---|---|---|
| 평면 | 0 | 1.4835 rad (85°) | 24.0 |
| 측면 A | 0 | 0.075 | 24.0 |
| 측면 B | π | 0.075 | 24.0 |

카메라 거리는 캔버스의 실제 화각에서 역산한다 — 수직 FOV 36°, 가로는 종횡비로 확장한
`hFOV = 2·atan(tan(vFOV/2)·aspect)` 를 써서 설비 폭·높이가 프레임에 꼭 차도록 맞추고 6 % 여유를 둔다.
정확히 π/2 로 내려다보면 `lookAt` 의 up 벡터가 퇴화하므로 평면은 85° 로 둔다.

## 다시 뽑는 법

미니앱 원본에는 카메라를 밖에서 조종할 방법이 없다. 그래서 스크래치 사본에 훅 세 개를 주입한 뒤 찍는다
(주입 지점은 반드시 해당 변수 선언 뒤여야 한다 — TDZ):

- `aim(x,y,z,d,yaw,pitch)` → `const cameraTarget` 선언 뒤
- `bboxPlant()` — `parts` + `unifiedWet` + `panelInfeed` 합집합. 지반·그리드를 빼려고 씬 전체 대신 이 셋만 쓴다
- `screenRect()` — bbox 8모서리를 `Vector3.project(camera)` 로 화면 픽셀에 투영해 실제 차지하는 사각형을 돌려준다

찍을 때는 캔버스의 형제 요소를 전부 `visibility:hidden` 으로 두어 UI 오버레이를 지우고,
`screenRect()` 결과로 스크린샷을 크롭한다. 36 m × 6 m 짜리 입면을 2.18 종횡비 프레임에 넣으면
위아래가 크게 비므로, 크롭은 선택이 아니라 필수다.

세션 스크래치의 `shots3.mjs` 가 이 과정을 그대로 담고 있다. 컨테이너가 재기동돼 스크래치가 비었으면
위 설명대로 다시 작성하면 된다.
