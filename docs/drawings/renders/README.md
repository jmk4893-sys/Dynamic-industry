# 플랜트 전경 렌더

`pv-recycling-miniapp.html` (DD-R4) 의 3D 씬을 조립(시뮬레이션) 모드에서 그대로 찍은 것이다.
손으로 그린 그림이 아니라 미니앱과 같은 지오메트리·재질·조명을 쓰므로, 미니앱이 바뀌면 이 그림도
다시 뽑아야 한다.

| 파일 | 시점 | 크기 |
|---|---|---|
| `plant-view-top.png` | 평면 — 거의 수직(85°) 하향 | 2604 × 882 |
| `plant-view-side-a.png` | 측면 A — +z 에서 −z 를 봄. 투입부가 왼쪽 | 2604 × 617 |
| `plant-view-side-b.png` | 측면 B — −z 에서 +z 를 봄. 측면 A 의 반대편 | 2604 × 617 |

습식부 데크는 밝은 회색 강재 그레이팅이다. 이전 판에서는 `material.frame`(metalness 0.76 · 환경맵 없음)
이라 평면에서 L≈15 의 검은 판으로 잡혀 그 위 장비를 눌렀다. 지금은 L≈160 으로, 스튜디오 배경(L≈114)
보다 밝고 중간톤 장비가 그 위에서 읽힌다.

습식부에는 ST-201 2층 데크 난간(H1,100·중간대·토보드 100)과 접근계단(유효폭 800·경사 38.8°),
부유선별 셀 라우더(FC-011 360° / FC-021 single lip / FC-031 180°), 탱크 맨홀·노즐·레벨게이지,
배관 행거·스탠션 33개소, H형강 기둥(H250/H200), 펌프 스트레이너·체크밸브가 서 있다.
야드 열(z ≈ 4.6)에는 WB-001 트럭 계량대, SP-601 시료 축소탑·LAB-601 분석실,
BB-501/502 빅백 충진 스테이션이 들어와 상업 플랜트의 거래 경계를 이룬다.
건식 용기에는 폭발 벤팅 패널(적색)·화염 차단밸브·스파크 검출·접지 본딩(녹색)이 붙었다.
장착 하드웨어도 형상으로 있다 — 기둥 주각 거싯 92, 모터 베드·슬라이드레일 92,
방진마운트 272, 피로우블록 36, 베이스플레이트 53, 기초 앵커볼트 80.
BOM 에는 있는데 3D 형상이 없던 것을 채운 것이라, 이 그림은 BOM 과 형상이 일치하는 상태를 보여 준다.

회사 심볼 마크가 장비 외장 여섯 곳에 붙어 있다 — 건식은 ICSH-301 점검커버 · PLC-101 반 도어 ·
HSG-101 전면도어, 습식·야드는 CH-601 칠러 +x 단면 · LAB-601 분석실 정면 · WB-001 계량 키오스크.
전부 가려지지 않는 평면을 골랐다(곡면 동체에 붙이면 모서리가 들뜬다). 도형은 콘솔 헤더의 SVG 와
같은 정의(`brand/brand-mark.json` → 미니앱 `BRAND_MARK`)에서 나오며, 원본 아트워크에서 추출한 값이다.

회로 재설계분도 들어와 있다 — SC-500 이 2단(1단 2 mm 스캘핑 · 2단 500 µm 폐회로)으로 넓어졌고
(W700 → 800), 1단 오버가 나가는 `BIN-102` 백시트 폐기빈과 그 벤트가 x ≈ 2.6 에 서 있다.
후단은 구리 산물이 한 빈(`BIN-Cu`, x 4.30)으로 모이도록 정리돼 종전 중량 제품빈이 빠졌고,
SS-201 ≥75 µm 를 나르던 RC-201 진공반송은 도착지가 HSG-101 에서 이 구리 제품빈으로 바뀌어
랙 상단 티어를 2.6 m 만 달린다.

## 촬영 기준

설비 실범위 (지반·그리드 제외) **36.05 × 9.55 m · 높이 6.18 m**
— x −14.10…21.95 / y −0.65…5.53 / z −3.41…6.14.

| 시점 | yaw | pitch | distance |
|---|---|---|---|
| 평면 | 0 | 1.4835 rad (85°) | 25.7 |
| 측면 A | 0 | 0.075 | 25.7 |
| 측면 B | π | 0.075 | 25.7 |

카메라 거리는 캔버스의 실제 화각에서 역산한다 — 수직 FOV 36°, 가로는 종횡비로 확장한
`hFOV = 2·atan(tan(vFOV/2)·aspect)` 를 써서 설비 폭·높이가 프레임에 꼭 차도록 맞추고 6 % 여유를 둔다.
정확히 π/2 로 내려다보면 `lookAt` 의 up 벡터가 퇴화하므로 평면은 85° 로 둔다.

## 다시 뽑는 법

미니앱 원본에는 카메라를 밖에서 조종할 방법이 없다. 그래서 스크래치 사본에 훅 세 개를 주입한 뒤 찍는다
(주입 지점은 반드시 해당 변수 선언 뒤여야 한다 — TDZ):

- `aim(x,y,z,d,yaw,pitch)` → `const cameraTarget` 선언 뒤
- `bboxPlant()` — `parts` + `unifiedWet` + `panelInfeed` 합집합. 지반·그리드를 빼려고 씬 전체 대신 이 셋만 쓴다
- `screenRect()` — bbox 8모서리를 `Vector3.project(camera)` 로 화면 픽셀에 투영해 실제 차지하는 사각형을 돌려준다

찍을 때는 캔버스의 형제 요소를 전부 `visibility:hidden` 으로 두어 UI 오버레이를 지우고,
`screenRect()` 결과로 스크린샷을 크롭한다. 36 m × 6 m 짜리 입면을 2.18 종횡비 프레임에 넣으면
위아래가 크게 비므로, 크롭은 선택이 아니라 필수다.

세션 스크래치의 `shots3.mjs` 가 이 과정을 그대로 담고 있다. 컨테이너가 재기동돼 스크래치가 비었으면
위 설명대로 다시 작성하면 된다.
