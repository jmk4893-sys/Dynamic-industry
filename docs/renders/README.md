# 전처리 플랜트 전경 렌더

[docs/drawings/pv-preprocess-plant.html](../drawings/pv-preprocess-plant.html) 의 3D 장면에서
그대로 찍은 것이다. 별도 모델이 아니므로 **도면이 바뀌면 이 사진도 다시 찍어야 한다.**

```bash
npm i playwright && npx playwright install chromium
node tools/render_plant_views.mjs docs/drawings/pv-preprocess-plant.html docs/renders
```

프레이밍은 손으로 잡지 않는다. 스테이션 셸의 실제 바운딩박스를 재서 시선축에
투영하고, 그 반치수에서 캔버스 비율과 카메라 거리를 파생시킨다. 장비가 늘거나 줄면
사진의 구도도 따라 바뀐다.

|---|---|---|---|

REV.23 에서 유리제거셀(GRM-401)이 하류에 붙어 담기는 실치수가 43.80 → **58.14 m** 로
늘었다. 프레이밍이 파생값이라 캔버스 비율도 따라 납작해졌다 — 손으로 맞춘 것이 아니다.

## 읽는 법

**정투영이 아니라 사진이다.** 화각을 14° 까지 좁히고 45–48 m 물러서서 정투영에 가깝게
만들었지만 원근은 남아 있다. 치수를 재려면 이 사진이 아니라 2D 제작도를 봐야 한다.

**축 대응.** 월드 +X 는 하류(공정 진행 방향), 월드 +Z 는 배치도 Y 증가 방향
= 보행·정비 통로(Y 7,100–8,300)측이다. 후자는 AFR 존만 Y 로 비대칭(1,200–6,800)인데
3D 에서도 같은 구간이 +Z 로만 (−1.79 … +3.78) 비대칭한 것으로 확인했다. 그래서
`02-front` 는 통로에서 본 것이고 `03-rear` 는 그 반대편이라 좌우가 뒤집힌다.

**그림자는 끄지 않았다.** 평면도에서 높이를 읽을 수 있는 유일한 단서다. 장비 옆에
비스듬히 깔린 연한 파란 면은 도형이 아니라 주광의 그림자다.

**안개는 렌더 동안만 껐다.** 장면은 근거리 시점을 전제로 안개가 걸려 있어, 45 m 밖에서
그대로 찍으면 전체가 회색으로 덮인다.

**애니메이션은 t = 30 s 에서 정지시켰다.** 라인에 패널이 물려 있는 상태다 —
빈 라인이 필요하면 `tools/render_plant_views.mjs` 의 `FREEZE_S` 를 바꾼다.
