# RFC 계열 연속 부선조 개념도 — 검증 결과 및 재작도 지시서

> **용도** — 2025-09에 작도된 인포그래픽 "REFLUX™ FLOTATION CELL (RFC) 구조, 유동 원리 및
> 주요 구성요소 (for PV Recycling)"의 검증 결과다. 이 문서만 보고 같은 구성의 그림을
> 다시 그릴 수 있도록 정정 사항과 확정 수치를 담았다. **아래 지시에 따라 재작도할 것.**
>
> 검증 근거 — RFC 계열 문헌(Dickinson & Galvin 2014; Cole et al. 2022; Jiang et al. 2022)과
> 사내 설계 계산(`docs/flotation-separator-design.md` §5.2, `src/flotation_design/rfc.py`,
> 정정판 도면 `docs/drawings/ag-flotation-rfc-reference.html` DWG-101~104).

## 0. 총평

구역 배치(위: 세정·역유동 기포층 / 아래: 경사채널 / 최하부: 테일링)와 경사채널
파라미터는 맞다. 그러나 **공기 주입 위치, 다운커머 형상, 상부 거동(froth), 사양표
숫자**가 틀렸고, 패널 간 자기모순(패널 1·2 ↔ 패널 5)이 있다. 명칭도 교체해야 한다.

## 1. 명칭·표기 (필수)

- 제목의 **"REFLUX™ FLOTATION CELL" 사용 금지** — REFLUX™는 FLSmidth의 등록상표다
  (뉴캐슬대 원천기술). 회사 로고가 들어가는 자료에 타사 상표·™ 기호를 쓰지 않는다.
- 제목은 **"세척수 bias 연속 부선조 (RFC 계열)"** 로, 부제에 "Wash-Water-Biased
  Continuous Flotation Cell" 병기.
- 각주로 다음 문구 유지: *"본 공정은 호주 가출원 AU 2025902821 관련 — 상업화 전
  실시권 검토 필요."*

## 2. 구조 정정 (그림에 반영할 것)

| # | 원본 표현 | 판정 | 정정 |
|---|---|---|---|
| 1 | 압축공기를 **동체 하부 측벽**으로 주입 (패널 1·2) | ✗ | 공기는 **전량 최상부 다운커머의 고전단 스파저**로 주입. 동체에는 공기 노즐이 없다. 하부 스파징은 컬럼 부선기 방식이다. 패널 5(스파저가 다운커머에 붙은 그림)가 맞으니 그 방식으로 통일 |
| 2 | 다운커머가 **동체 전 높이를 관통**해 경사채널을 지나감 | ✗ | 다운커머는 상부에서 중심으로 관입하고 **토출단은 라이저 상부에서 끝난다**(경사채널 불관통). 관통하면 급광이 기포층을 거치지 않고 미광으로 직행한다 |
| 3 | 급광이 **동체 측면 중간 높이**로 유입 | ✗ | 급광은 **최상부에서 다운커머 상단**으로 유입 |
| 4 | 상부 "세정 존"을 **거품층(froth)** 처럼 표현 | ✗ | **flooded 운전** — 자유표면·froth 없음. 세척수 분배기가 상단을 밀폐하고, 기포 체적분율 ≈ 0.5의 농후 기포혼합체가 상단까지 찬다. 세정은 froth washing이 아니라 기포층을 관통하는 **하향 bias** |
| 5 | bias 표기 없음 | ✗ | 핵심 제어변수 **Jb = Jw − Jo = 0.81 − 0.56 = 0.25 cm/s** 를 단면도에 하향 화살표 + 수식으로 명기 |
| 6 | 정광 상부 환형 월류 | ✓ | 유지 — 세척수 분배기 직하 둘레의 환형 런더 |
| 7 | 경사채널 존이 라이저 아래, 테일링 존 최하부 | ✓ | 유지 |
| 8 | "역유동 기포층 (Reverse Fluidized Bubbly Bed)" 용어 | ✓ | 유지 — 문헌 용어와 일치 |
| 9 | 경사채널 리플럭스 화살표(기포 상향 / 슬러리 하향) | ✓ | 유지. "기포는 판의 **하향면(아랫면)** 을 따라 상승"을 주석으로 추가 |

## 3. 사양표 전면 교체 (패널 8)

원본 표의 수치 오류: 처리 용량 단위 오기(0.2–0.5 **m³/h** ← 건조 고체 0.2–0.5 **t/h**),
그 값과 공기 유량(0.1–0.5 m³/min)을 조합하면 공기:급광 = 60:1이 되는 자기모순(실제 1:1),
직경 과대(600–1000 mm), "세정 길이 = 처리량의 0.5–2배"라는 무의미 항목. 아래 표로 교체.

| 항목 | 사양 (확정) | 비고 |
|---|---|---|
| 처리 용량 | 건조 고체 평균 0.30 / 최대 0.50 t/h · 슬러리 6.93 m³/h | 설계점 7 wt% 고체 (평균 부하는 4.22 wt%) |
| 동체 내경 D | **Ø350 mm** (단면적 0.0962 m²) | flux 상사 스케일업 결과 |
| 전체 높이 H | ≈ 3.6 m (경사판 내장형) ~ 4.2 m (모듈 적층형) | 라이저 2.40 m 포함 |
| 다운커머 | Ø65–80 (추정) · 상부 중심 관입, 토출단은 라이저 상부 | 관경은 상세설계 확정 |
| 급광 flux Jf | 2.0 cm/s · 6.93 m³/h | |
| 공기 flux Jg | 2.0 cm/s · 6.93 m³/h (= 0.12 m³/min) | **Jg : Jf = 1 : 1** · 송풍기 0.37 kW @ 60 kPa |

| 월류수 Jo / bias Jb | 0.56 / **0.25** cm/s | Jb = Jw − Jo, 하한 0.20 — 미광 배출과 협조 제어 |
| 기액 체류시간 | 1.0 min | 라이저 기준 |

| 테일링 배출 | 하부 원추 + 제어밸브 (bias 협조) | 구경은 상세설계 |
| 재질 | 상세설계 확정 항목 | SUS304/316 표기는 참고 수준으로만 |

## 4. 패널별 재작도 지시

1. **전체 조립도(3D)** — 하부 공기 배관 삭제. 급광·공기 배관을 모두 최상부 다운커머로.
   다운커머는 상부 약 1/3 깊이까지만. 나머지 구성(경사채널 패키지, 하부 원추, 상부 런더) 유지.
2. **단면도** — 존 순서 유지(세정/역유동 기포층/경사채널/테일링). 단, 세정 존을 froth 로
   그리지 말고 전 구간을 같은 기포혼합체로. 다운커머 토출단(경사채널 위)을 명확히.
   하향 bias 화살표와 수식 Jb = Jw − Jo = 0.25 cm/s 추가.
3. **상부 상세** — 유지하되 "세척수 분배기가 자유표면을 밀폐(flooded)" 주석 추가.
4. **경사채널 상세** — 유지. 수치는 70° · 12 mm · 판 1.0 m 로 확정 표기.
5. **다운커머/스파저 상세** — 원본이 정확함. 기포 생성 범위만 0.5–1.0 mm 로 수정.
   이 패널의 구성을 패널 1·2에도 일관되게 적용할 것.
6. **평면도** — 유지.
7. **운전 흐름도** — "원료+공기(다운커머에서 접촉) → 기포-입자 접촉 → 역유동 기포층 →
   경사채널 분리·세정" 유지. 마지막 단계 앞에 **"세척수 하향 bias 세정 (Jb = 0.25 cm/s)"**
   블록 추가.
8. **사양표** — §3 표로 전면 교체.

화살표 범례(노랑 = 기포+소수성 입자 상승 / 파랑 = 세척수 하향 / 갈색 = 슬러리·미광 하강)는
유지하고, 공기 화살표는 다운커머 상단으로만 들어가게 한다.
