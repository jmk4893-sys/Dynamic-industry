## 3. 정정한 것 — [2] 전면 삭제는 추적성 파괴

외부 REV D는 [2]를 도면에서 완전히 지웠으나 **[2]가 출처인 수치(Jf·Jg·Jw·Jb, 기액 체류
1 min, 기포 0.5–1.0 mm)는 그대로 "내부값"으로 유지**했다. 이는 출처 세탁이지 엄격화가
아니다 — 숫자의 계보가 끊기고, 남겨둔 주기("문헌 [2] 공정은 AU 가출원…")의 [2] 참조가
공중에 뜬다(본문 6곳). 외부 검토 스스로 제안한 "UNVERIFIED EXTERNAL PREPRINT DATA
부록" 형식으로 복원했다:

- DWG-104 참고 표에 **"미검증 프리프린트 참고 [2]"** 행 (성능 인용 금지 라벨 포함)
- 설계기준 요약 캡션·요소표 근거에 "시험조건 출처: 프리프린트 [2]" 각주
- 푸터 [2] 정의 복원, 장치형식 주기에 계산서 §5.1의 "RFC 계열로 판단(확정 아님)" 기록 복원

저장소 거버넌스와도 정합: [2]는 README·계산서·`tests/test_references.py`가 재현을
고정하는 **1안의 1차 설계 근거**다. 도면에서 성능 보증으로 쓰지 않는 것(동의)과
출처에서 지우는 것(반대)은 다른 문제다.

## 4. §7 "REV E 확인사항" 답변

1–3. **99.7 % / 48.8 wt% / 100×80 mm / 22 kg / 42–90 min**: 저장소 `references.py`가
   [2]에서 전사·고정한 값이며(테스트 검증), 언론 보도가 회수율·수율·연속시간을 정합
   확인. 원문 페이지/figure 번호는 chemrxiv.org 차단으로 본 세션에서 제시 불가 —
   **PDF를 세션에 첨부해 주면 문항 1–3을 원문 기준으로 종결한다.**
2. 장치 명칭: 저장소는 처음부터 "논문은 형식 미명시, RFC 계열로 판단"을 명문화(§5.1).
   원문 도면 대조 전 확정하지 않는다는 데 동의 — 주기에 그대로 반영.
4. 장치가 RFC가 아니어도 영향 범위는 제한적: 구조 근거는 이미 [3]만 사용, [2]는
   시험조건·성능 참고. 소스 패밀리 분리는 반영 완료.
5–6. 게이트 동의. cold-flow 순서 C-20→C-06(간격 내림차순)은 막힘 위험 오름차순과
   일치 — REV C 스코핑 표의 권고와 동일.
