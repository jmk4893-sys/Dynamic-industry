# 클로드 설계 검토 및 통합 적용 결정

## 결론

현재 프로젝트의 기본 제작안은 **기계식 러퍼-스캐빈저-클리너 3단**이다.
클로드 설계의 문헌 보정, 폐회로 질량수지, 중공축, 탈수 계통, 테스트 구조는
채택한다. 연속 1단 부선조의 99.7% Ag 회수율은 기술·특허 대안으로 유지하되,
현재 공장 원료와 0.5 t/h 규모에서 확인되기 전에는 제작 성능보증에 사용하지 않는다.

## 채택한 항목

| 항목 | 통합 설계 반영 |
|---|---|
| 실증 운전 범위 | 7 wt% 고형분, 평균/최대 0.30/0.50 t/h |
| 셀 사이징 | 러퍼·스캐빈저 Ø1,000 x 1,300 mm, 클리너 Ø400 x 650 mm |
| 장비 표준화 | 러퍼·스캐빈저 동체·Ø350 로터·4 kW 구동·OD60/ID20 축 공용 |
| 중공축 급기 | R/S 8 x Ø5 mm, C 8 x Ø3 mm 로터 허브 분산구 |
| 복합입자 | `Ag_locked_gangue` 보존 성분으로 단별 중복 생성을 방지 |
| 탈수 | 정광·미광 농축조 및 필터프레스를 분리해 교차오염을 방지 |
| 여액 | 정상 품질이면 0.472 m3/h를 러퍼 급광으로 직송 |
| 검증 | 문헌 재현, 질량·물 수지 폐합, 도면-계산 동기화, MP4 생성 스모크 테스트 |

## 보완해 적용한 항목

### 여액 직송

여액은 러퍼로 되돌리되 다음 permissive를 둔다.

- 여액조 정상 수위
- 환류펌프 정상
- TSS/탁도, pH, 전도도, 온도 및 잔류약품 허용범위
- 불합격 시 러퍼 입구 차단 및 별도 off-spec 탱크 우회
- DN25 저유속 구간은 정기 고유량 플러시

### 현재 공장 원료 적용 경계

논문 원료는 패널에서 분리한 셀 분획을 습식 로드밀로 분쇄한 재료다. 현재 검토 중인
`고속분쇄기-다단체-열처리 또는 attrition` 블랙파우더는 다음 항목이 다를 수 있다.

- 입도분포와 Ag 노출도
- EVA·백시트·탄화잔사
- Cu·Al 함량
- 펄프 점도와 기포 안정성
- 여액 재순환에 따른 이온·약품 축적

따라서 P80 66 um 하나만 맞는다고 논문 성능을 이월하지 않는다. 실제 원료의 PSD,
MLA/TIMA 또는 SEM-EDS 노출도, LOI/TGA, 조성, 레올로지와 locked-cycle 결과를 함께
확인한다.

## 조건부 또는 보류 항목

| 항목 | 결정 |
|---|---|
| 연속 1단 부선조 99.7% | 실제 원료 파일럿 및 실시권 확인 전 대안기술 |
| AEROPHINE 3418A·AEROFLOAT 242 각 300 g/t | 습식분쇄 연속시험의 시작점; 실제 원료 DOE로 최적화 |
| MIBC 30 ppm | 시작점; 재순환수와 잔류 유기물의 거품 영향을 포함해 조정 |
| 결합 맥석비 1.1 | 논문 정광 품위 상한을 재현하는 보정값; 보편 물성값이 아님 |
| 축 임계속도 | 예비 외팔보 검산만 채택; 실제 베어링 스팬·로터 질량·불평형으로 FEA 재검증 |
| 입자 애니메이션 | 작동원리 시각화; CFD/DEM 또는 성능보증으로 사용하지 않음 |

## 제작 전 필수 시험

1. 실제 블랙파우더 20-50 kg characterization
2. 7 wt% 회분식 약제·공기·시간 DOE
3. 러퍼-스캐빈저-클리너 locked-cycle
4. 농축 침강시험 및 flocculant screening
5. 정광·미광 filter leaf test
6. 확정 축 조립체 modal/critical-speed 및 진동 검증
