# MP-50 CAD 파일

`python tools/mp50_cad.py` 가 만든다. 손으로 고치지 말 것 — 다시 생성하면 덮어쓴다. 좌표는 모두 `mp50_separator` 의 확정 기하에서 나온다.

| 폴더 | 무엇 | 쓰는 곳 |
|---|---|---|
| `dxf/cut/` | 절단 윤곽만. 1:1, 글자 없음, 원점은 소재 왼쪽 아래 | 레이저·워터젯 CAM |
| `dxf/dwg/` | A3 가공도. 틀·표제란·치수·구멍표·주기 | 현장 인쇄 |
| `step/` | 3D 솔리드 (AP214). 평면·원통·원뿔 해석면 | 기계가공·간섭 확인 |

DXF 는 R12(AC1009) 이고 글자는 cp949 다 — 한국 현장 CAD 가 그대로 읽는다. STEP 은 AP214 이며 OpenCascade 로 부피와 다양체를 확인했다.

## 3D 가 실물과 다른 곳

말거나 굽히는 부품은 **자르는 형상**과 **완성 형상**이 다르다. 자르는 것은 DXF 에, 완성은 STEP 에 있다.

| 부품 | 다른 점 |
|---|---|
| `A-01` | 3D 는 말고 난 원통이다. 노즐 구멍은 평판에서 뚫으므로 DXF 전개도에만 있다. |
| `A-02` | 3D 는 말고 난 원뿔이다. 자르는 것은 왼쪽 부채꼴이다. |
| `A-04` | 3D 는 대표 1 본이다. 나머지는 노즐표의 호칭으로 같은 방식. |
| `C-05` | HOLD 형상이다. 벤더 GA 가 나오기 전에는 발주하지 않는다. |
| `C-06` | 3D 는 말고 난 원통이다. 공구 없이 열리는 개방식이라 인터록은 걸지 않는다. |
| `D-02` | 3D 는 허브와 날개 4 매를 따로 담았다. 날개는 취부각 45° 로 세워 용접한다. |
| `D-03` | 3D 는 허브와 날개 4 매를 따로 담았다. 날개는 취부각 45° 로 세워 용접한다. |
| `F-01` | 3D 는 굽히기 전 곧은 관이다. 굽힘 후 PCD 와 평면도는 가공도의 치수로 잡는다. |
| `F-04` | 3D 는 굽히기 전 평판이다. |
| `G-01` | 3D 는 말고 난 링이다. |
| `G-02` | 구멍은 대표 구간만 담았다. 실제는 전면 타공이라 6 천 개를 솔리드로 담으면 열리지 않는다. |
| `G-04` | 3D 는 굽히기 전 곧은 봉이다. |

## 질량이 부품표와 다른 곳

CAD 질량은 구멍을 뺀 실형상이고, 부품표는 외형 기준 추정이거나 사 오는 부속(페룰 등)을 포함한다. 아래가 그 차이다.

| 부품 | CAD kg | 부품표 kg | 왜 |
|---|---|---|---|
| `A-03` | 0.124 | 0.344 | 부품표는 2" 페룰(0.22 kg)을 포함한다. CAD 는 만드는 관만 센다 |
| `A-04` | 0.034 | 0.290 | 부품표는 9 본 평균에 페룰 0.18 kg 을 더한 값. CAD 는 ½" 대표 관 1 본 |
| `A-08` | 0.144 | 0.167 | 부품표는 70 × 50 외형으로 셌다. CAD 는 모따기 18 과 Ø20 구멍을 뺀다 |
| `B-04` | 0.027 | 0.204 | 부품표는 페룰 포함 평균. CAD 는 관만 |
| `C-05` | 1.076 | 4.000 | 구동부 HOLD — 부품표 4.0 kg 은 어댑터 일체의 개략값이고 CAD 는 판 한 장이다. 벤더 GA 로 확정된다 |
