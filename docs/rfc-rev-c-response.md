# REV C 회신 — 외부 기술검토(REV B)에 대한 답변과 반영 내역

> 외부 검토문서(`docs/external-review/2026-09-22-rev-b-*.md`)의 PART J(수정 요청 12항)와
> PART K(질문 Q1–Q5)에 대한 회신이다. REV C 도면은
> `docs/drawings/ag-flotation-rfc-reference.html` 로 갱신했다.

## 1. 검토 총평 — 대부분 수용

상태등급 분리([LITERATURE]/[DESIGN BASIS]/[PILOT VARIABLE]/[PERFORMANCE])와
채널 간격의 카세트화는 올바른 엔지니어링 거버넌스이며 전면 수용했다.
RC의 3–6 mm 전단-리프트 논리를 RFC에 이월하지 않는다는 판단도 옳다
(RC=밀도·침강, RFC=기포 부착·리플럭스 — 본 저장소의 RC/RFC 비교 검토와 일치).

## 2. 질문 Q1–Q5 답변

**Q1. 12 mm를 PV/미세광물 RFC에서 직접 검증한 공개 자료가 있는가?**
없다. 12 mm는 `rfc.py`의 내부 기본값(계산서 §5.2에 그대로 인용)이며 문헌 검증값이
아니다. REV C부터 "계산서 내부 후보값(C-12)"으로 강등하고, 문헌 기준은 ≈20 mm(C-20)로
표기했다.

**Q2. Ag 99.7 % / 46.3 wt%가 실제 RFC 장치의 결과인가?**
분리해서 답해야 한다. **99.7 % / 48.8 wt%** 는 문헌 [2](Saffarian·Galvin·Firouzi,
ChemRxiv 2026)의 **연속 세척수-bias 부선조 실증값**(단면 100×80 mm, 실제 PV 셀 분획
22 kg, 정상상태 42–90 min)이다. 논문이 장치 형식을 명시하지 않아 "RFC 계열로 판단"이
저장소의 공식 입장이며(계산서 §5.1), **46.3 wt%** 는 잠금 맥석 모델을 넣은 내부 계산값
(계산서 §5.4)이다. 따라서 "본 Ø350 장치의 검증성능"이 아니라는 지적은 타당하고,
REV C에서는 keyfacts에서 제거하되 DWG-104에 "성능 참고값(본 장치 미검증): 문헌 [2]
99.7 % · 48.8 wt%, 계산 목표 46.3 wt%"로 남겼다. **완전 삭제는 하지 않았다** — [2]는
'외부 참고문헌 중 하나'가 아니라 본 설계의 1차 근거(README·`tests/test_references.py`가
재현 검증)라서, 값의 계보를 지우면 설계 추적성이 끊긴다.

**Q3. Ø350 × 2.40 m는 문헌 실증 치수인가?**
아니다. 실증 장치 단면은 100×80 mm이고, Ø350×2.40 m는 flux 상사(단면적 비례)로
스케일업한 내부 계산값이다. [DESIGN BASIS] 태그를 도면 전반에 반영했다.

**Q4. 중앙 원형 다운커머가 상업 RFC의 필수 geometry라는 근거가 있는가?**
보편 표준이라고 단정할 근거는 없다. 실험실 RFC에서 동심 원형 다운커머가 일반적이지만
사각 단면·복수 다운커머 등 변형이 존재한다. REV C의 DWG-101/102에 "중앙 배치는
프로토타입 선택"으로 명시했다.

**Q5. 6–20 mm 간격 비교의 예상 거동 — 1차 스코핑 (CFD 아님)**

공통 조건: Ø350, 미광측 겉보기 하향 flux ≈ 2.25 cm/s → 채널 방향 액속 u ≈ 2.4 cm/s
(판 두께 무시), 판 70°·길이 ≈1 m.

| 항목 | 1차 추정 | 간격 의존성 |
|---|---|---|
| 채널 수 N (Ø350) | N ≈ 329/s: 6→55 · 10→33 · 12→27 · 15→22 · 20→16 | ∝ 1/s |
| 압력손실 (층류 평행판) | 12 µuL/s²: s=6 → ≈8 Pa · s=20 → ≈0.7 Pa | 전 구간 무시 수준 |
| 기포 리플럭스 (0.5–1.0 mm, v_b ≈ 5–10 cm/s) | v_b·sin70° = 4.7–9.4 > u 2.4 → 채널 안에서도 순상승, 자력 탈출 | s 무관 — 전 카세트 성립 |
| 미세기포 (0.2 mm, v_b ≈ 2 cm/s) | 순하강 0.5 cm/s이나 판 횡단(s/(v_b·cos70°))로 회수 — s=20에서도 하강 ≈1.5 cm ≪ 판 1 m | s 무관 — 기하적 여유 큼 |
| 막힘·오염 | 플레이크 Al·EVA 잔사, 응집체 가교 | **s<10 mm에서 위험 급증 — C-06는 cold-flow 선행** |
| Si 미립 미광 침강(2차 기능) | 침강 면적 ∝ N → s 작을수록 미광 청정도 유리 | s ↓ 유리 |
| Ag 회수율 차이 | 수리학보다 막힘·분배 불균일·판면 기포 유착이 지배할 전망 | 실험으로만 판별 |

결론: **수리학만으로는 6–20 mm 전부 성립**하고 차이는 2차 효과에서 난다 — 카세트
비교시험(Gate B1–B3) 계획이 옳다. CFD는 분배 불균일과 채널 입구 재순환 확인용으로
cold-flow와 병행할 것을 권한다.

## 3. 외부 검토문서 쪽 정정 필요 사항

1. **급광 입도** — PART F의 "25–75 µm"는 저장소 기준 **P80 66 µm**(습식 로드밀)와
   다르다. 주 분포 구간 표현으로는 무방하나 Gate B3 시험 기준은 P80 66 µm로 둘 것.
2. **문헌 [2]의 지위** — "외부 PV Ag flotation 연구"가 아니라 본 설계의 1차 근거다
   (Q2 참조). "본 장치 미검증" 라벨에는 동의.
3. **서지 미확정 인용 2건** — "Minerals Engineering (2026) 110422"는 저자·제목이 없어
   검증 불가, "RFC fast-flotation 연구(70°·925 mm·≈20 mm)"도 서지 미기재. 인용을
   확정하기 전에는 채택 보류를 권한다(70°·≈20 mm 자체는 별도 문헌으로 뒷받침됨).
4. **REV-B HTML 잔존 결함** — 자체 원칙과 모순되는 표기가 남아 있었다:
   DWG-101/102의 정광 라벨 "46.3 wt% Ag"(2곳), DWG-103 "≈27 채널"(12 mm 전제),
   PART J #9·#10(리플럭스/하강류 화살표 라벨)·#11(프로토타입 배치) 미적용,
   lede가 REV A 문구 그대로. → 모두 REV C에서 처리.
