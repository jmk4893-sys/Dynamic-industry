# 라미네이트 급광에서의 Ag 회수 — 설계와 그 한계

**목적** — 미니앱([pv-recycling-miniapp.html](drawings/pv-recycling-miniapp.html))이
다루는 **EVA 를 안은 라미네이트 파쇄물**에서 Ag 를 회수하는 회로의 설계와,
그것이 실제로 무엇을 달성하고 무엇을 달성하지 못하는지를 적는다.

| 항목 | 값 |
|---|---|
| 급광 | 라미네이트 파쇄물 300 kg/h · Ag **2,945 g/t** · **폴리머 45–62 wt%** |
| 구성 | **2 단** — 폴리머 역부선 → (분쇄) → FC-101 리플럭스 Ag 부선 |
| 플랜트 Ag 회수율 | **97.7 – 98.7 %** (목표 ≥99 % **미달**) |
| 정광 | **8.4 kg/h @ 10.2 – 10.3 wt% Ag** (목표 ≥10 wt% 달성) |
| 관문 | **4 건** — 셋이 회수율을, 넷째가 품위를 가른다 |
| 신설 전력 | LCP-AG-101 27.3 kW · 플랜트 변압기 250 → **315 kVA** |

> **이 문서의 값은 [flotation-separator-design.md](flotation-separator-design.md)
> 와 다른 물질에 대한 것이다.** 그쪽은 유리·폴리머가 제거된 **셀 분획**(Ag 0.59 wt%,
> 폴리머 없음)을 다루고 RFC 1 단으로 99.7 % / 46.3 wt% 를 낸다. 여기는 폴리머가
> 절반인 라미네이트다. 두 문서가 「300 kg/h」라는 같은 문자열을 쓰지만 같은 물질이
> 아니다.

---

## 1. 왜 2 단인가

종전 회로는 습식이 폴리머 역부선 하나뿐이었고, 그나마 ≤500 µm 산물 중
<75 µm 만 받았다. 결과는 이랬다.

| 배출구 | 급광 Ag 분배 |
|---|---|
| BIN-Cu (건식 구리 제품) | **80 – 81 %** |
| FP-301 Si 케이크 (습식 광미) | 18.7 % |
| BIN-102 백시트 폐기 | 0.51 % |
| **CF-204/BIN-204 「Ag 정광」** | **≈ 0.4 %** |

즉 Ag 의 대부분이 회로를 보지도 못하고, 습식에 들어온 것마저 역부선이라
광미로 갔다. 회수율 상한이 약 19 % 이므로 어떤 개선도 목표에 닿지 못한다.

바꾼 것은 둘이다.

1. **라우팅** — ≤500 µm 산물을 전량 습식으로 보낸다(케이스 A).
2. **회로** — 폴리머를 먼저 띄워 버리고(1 단), 남은 침강물만 분쇄해
   Ag 를 띄운다(2 단).

## 2. 라우팅 케이스 — 둘을 별개로 둔다

사용자 결정(2026-09-05)에 따라 두 라우팅을 서로의 하위 모드가 아니라 각자
수지를 갖는 **독립 구성**으로 둔다.

| 케이스 | 습식 급광 | BIN-Cu | 플랜트 Ag 회수율 |
|---|---|---|---|
| **A** ≤500 µm 전량 | 체 급광 255 kg/h 전량 | 정지 시 바이패스로만 | **97.7 – 98.7 %** |
| **C** <106 µm 만 | 106 µm 위 두 밴드 제외 | 제품으로 계속 | 약 25 % |

케이스 C 의 <106 µm 질량 몫은 `MODEL_PRODUCT_UNDER75_FRACTION` 과 마찬가지로
모델을 돌려 산물 PSD 에서 읽어야 하는 실측값인데 아직 없다. PSD 분위수 사이를
보간해 지어내지 않고 `null` 로 두었다 — 수지는 누적 원장에서 실제 밴드 질량을
읽으므로 영향이 없고, 케이스 C 를 활성화하면 듀티 표만 실측을 요구한다.

## 3. 회로

### 1 단 — 폴리머 역부선 (뜨는 것이 버리는 것)

```
급광 → AS-101 → AS-101B → FC-201 러퍼 ─거품→ FC-204 세척 클리너 ─거품→ AS-102 → FC-202 최종 클리너 ─거품→ 폴리머 배출
                              │                      │                                        │
                            광미                    광미 ────────────────────────────────────광미
                              ↓                       └──── FC-201 환류 ────┘
                        FC-203 스캐빈저 ─거품→ FC-201 환류
                              │
                            광미 = 침강물 → 2 단
```

환류가 두 갈래라 고정점 반복 40 회로 푼다.

### 2 단 — Ag 부선 (뜨는 것이 제품)

```
침강물 → CN-201 농축 → RM-201 로드밀 P80 66 µm → CT-101 조건조 → FC-101 리플럭스 부선
                                                                      │
                                                        거품 → PS-201 폴리싱 → BIN-204 Ag 정광
                                                        광미 → FP-301 Si 케이크
```

별도로 **FW-102** 가 BIN-102 로 나가는 백시트 박편을 마찰세척해 표면 미분을
습식으로 되돌린다.

## 4. 이 설계가 실제로 내는 값

같은 회로를 **서로 다른 두 기계**로 풀었다. 미니앱은 입자군별 부유도비
(B 1 · C 0.35 · A/Ac 0.03)에 완전혼합 1 차 모델을 걸고, Python 패키지
(`flotation_design.laminate_scenario`)는 성분별 2 속도 속도론에 연행을 얹는다.
두 모델은 서로를 베끼지 않았다.

| | 미니앱 | Python 패키지 |
|---|---|---|
| 회수율 (FC-101 0.990) | 97.71 % | 97.96 % |
| 회수율 (FC-101 0.997) | 98.40 % | 98.65 % |
| 정광 품위 | 10.3 wt% | 10.2 – 10.3 wt% |
| 1 단 폴리머 제거율 | 34.6 % | 27.3 % |

회수율이 0.25 pp, 품위가 0.1 wt% 안에서 붙는다. `tests/test_laminate_scenario.py`
의 교차 대조 시험이 이 일치를 강제한다.

**결론 — ≥10 wt% 는 달성, ≥99 % 는 미달이다.**

## 5. 99 % 까지 남은 0.6 pp 는 공정이 아니라 assay 다

손실 예산 1.0 % 에 대해 이 모델의 손실은 1.60 % 다.

| 손실점 | 급광 Ag 대비 |
|---|---|
| BIN-102 백시트 (FW-102 통과분) | 0.34 % |
| BIN-Cu | 0 % (케이스 A) |
| **1 단 폴리머 배출** | **0.97 %** |
| FP-301 광미 (FC-101) | 0.30 % |

폴리머 배출 0.97 % 중 **0.64 pp 가 B 군(탈락 백시트)을 100 g/t 로 둔
자리표시자 assay** 에서 나온다 — 배출 57 kg/h 중 56.3 kg 이 B 다.

    B 100 g/t (자리표시자) → 98.40 %
    B   0 g/t (Ag-free)   → 99.06 %

즉 **≥99 % 의 성부는 공정이 아니라 LAB-601 assay 가 먼저 가른다.**
아래 관문 3 건보다 이것이 앞선다.

## 6. 품위는 1 단이 아니라 2 단이 정한다

제안 단계에서는 1 단 역부선이 폴리머를 98.9 % 뗀다고 전제했다. **실제로는
34.6 % 다.** 역부선이 띄울 수 있는 것은 떨어져 나온 백시트(B)뿐인데, 급광
폴리머의 대부분은 A(45 wt%)·Ac(53 wt%) 입자 **안의** EVA 이고 그것은 셀에
붙어 있어 뜨지 않기 때문이다.

**EVA 는 「띄워 버릴 상」이 아니라 Ag 를 지닌 입자의 일부다.**

따라서 ≥10 wt% 는 2 단이 폴리머를 얼마나 밀어내느냐로 정해진다 — RM-201 이
P80 66 µm 로 갈아 EVA 를 Si 에서 떼고, FC-101 세척수와 PS-201 폴리싱이
그것을 걸러 낸다. 목표를 되짚으면 **≥10 wt% 에 0.94, 18.2 wt% 에 0.975** 가
필요하다. 이 값에는 근거가 없다.

## 7. 관문 4 건

| # | 관문 | 기준 | 확인 방법 | 가르는 것 |
|---|---|---|---|---|
| 1 | 총 해리도 | ≥ 0.994 | AS-101B 토출 시료 TIMA/SEM | 회수율 |
| 2 | FW-102 분진 세척률 | ≥ 0.34 | 급광·언더·오버 칭량 (또는 BIN-102 ≤ 66 g/t) | 회수율 |
| 3 | FC-101 광미 품위 | ≤ 43 g/t | RM-201 실제 산물로 파일럿 24 h | 회수율 |
| 4 | **2 단 폴리머 제거율** | **≥ 0.94** | RM-201 분쇄산물로 FC-101＋PS-201 벤치 | **품위** |

FC-101 회수율 자체도 단일값이 아니다. 문헌의 99.7 % 는 단일 90 min 시험이고
광미가 검출한계 이하이며, 정광 기준으로 닫으면 103.4 % 라 원자료 폐쇄 오차가
±4 % 다. 회분식의 비부선 2.4 %(기계식 점근 97.6 %)와도 양립하지 않는다.
그래서 **0.990 – 0.997 밴드**로 다룬다.

## 8. 3D 에 자리가 없는 신설 2 종

배치표에 대고 간섭을 검사한 결과 신설 9 종 중 7 종만 들어간다.

| 신설 | 필요 | 간섭원 | 해소안 |
|---|---|---|---|
| **AS-101B** | AS-101 직하류 1.12 m 각 | BR-101 · BM-101 호퍼 | 호퍼 이설 또는 AS-101 단일 대형화 |
| **FC-204** | 부선열 동측 1.46 m | 잔여 1.08 m (FC-203 동단 ~ 데크 동단) | 데크 동측 연장 또는 셀 축소 |

둘은 **수지에 이미 들어가 있으므로 위 회수율은 이 둘을 포함한 값**이다.
형상만 없다. 전기 부하도 LCP-AG-101 에 계상돼 있다(status 에 HOLD 표기).

## 9. 미확정 결정 위의 가정

| 결정 | 가정한 값 | 근거 |
|---|---|---|
| 3 · 용기 증설 | FC-204 190 L · AS-102 40 L · AS-101B 40 L | 제안서 권고 |
| 8 · 폴리싱 방식 | 밀도식 대신 100 µm 스크린 + 침부선별 | 100–500 µm 플레이크에 밀도분리는 물리적으로 의심스럽고 9 µm 이하 Ag 를 잃는다 |
| 9 · Cu 제품 정의 | 분쇄 전 선별 90 % | Cu 리본은 연성이라 분쇄되지 않고 종말속도가 컬럼 하향류를 넘는다 |

코드의 해당 상수에 「가정」·「HOLD」를 표기했고 시험이 그 표기를 강제한다.

## 10. 남은 것

- **LAB-601 assay** — B 군 100 g/t 는 자리표시자다. 이것이 99 % 의 성부를 가른다.
- **관문 4 건** 벤치·파일럿.
- **AS-101B · FC-204 배치** — 데크 연장 또는 기기 이설. 배치와 비용을 바꾼다.
- **변압기 315 kVA 증설** — 제안 단계 CAPEX 추정에 없던 항목이다.
- FC-101 라이선스(AU 가출원 2025902821) 검토.
