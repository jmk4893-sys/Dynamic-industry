## 지적 사항 (외부 도구에 회신)

1. **기반 리비전 어긋남** — 편집본이 REV C 기반이라 그대로 채택하면 REV D의 변경
   (46.3 라벨 제거, 채널간격 △, 설계기준 개칭, [1]~[4] 근거 체계, 프리프린트 각주)이
   롤백된다. 선별 병합으로 처리했으며, **이후 편집은 항상 최신 커밋본을 기준으로** 할 것.
2. 색상은 고정 hex 대신 문서 팔레트 변수를 쓸 것(다크 테마·인쇄 대응). 본 도면의
   기포색은 밝은 노랑이 아닌 금색(`--ag`)이므로 라벨도 "(금색)"으로 표기했다.
3. 리비전 매핑 — 인포그래픽 **REV.B2** ↔ 기준 도면 **REV E**.
