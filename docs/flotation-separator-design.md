# 태양광 셀 은(Ag) 회수 부유선별 설비 설계

**목적** — 폐 태양광 모듈(c-Si)에서 박리한 셀 분획으로부터 **은(Ag)** 을 부유선별로
농축해, 후단 침출·제련 물량을 약 1/79 로 줄인다.

| 항목 | 값 |
|---|---|
| 구성 | **어트리션 전처리 + 떨어진 EVA 분리 + 세척수 bias 연속 부선조 1단** (대안: 기계식 러퍼·스캐빈저·클리너 3단) |
| 평균 / 최대 처리량 | **0.30 / 0.50 t/h** (건조 고체) |
| 부선기 | **Ø350 mm × 라이저 2.4 m, 1기** |
| 전처리 | **어트리션 스크러버 팔각조 AF 390 mm × 2단** — EVA 박리 전용 (공통, 부선 성능 크레딧 없음) |
| 떨어진 EVA 분리 | **ES-1 Ø1.0 m × 2셀 + ES-2 Ø0.4 m** — 기포제만 쓰는 EVA 부선, 2안 동체 그대로 (공통) |
| 파일럿 시험 셀 | **PAS-1 회분식 20 kg, AF 260 mm, 1.5 kW 6극 직결** — AS-1 과 기하 상사, 블랙파우더 EVA 박리 비에너지 확정 (플랜트 설비 아님, REV C) |

| 물 계통 | **ES 앞은 청수, CT-1 부터 공정수** — 1안 최대 처리량에서 신수 6.37 / 블리드 6.43 m³/h (§5.9) |

| 정광 | **6.36 kg/h @ 46.3 wt% Ag** (농축비 78배) |
| 미광 Ag 품위 | 18 g/t |
| 기액 체류시간 | **1 분** |
| 설치 전력 | **6.5 kW** (부선 계통, 탈수 라인 포함) + 전처리 15.0 kW (어트리션 4.8 + EVA 분리 10.2) = **21.5 kW** |

## 1. 이전 설계에서 무엇이 바뀌었나

문헌 없이 일반 광물부선 관행으로 추정했던 이전 판과 비교하면, 바뀐 것이 바뀌지 않은
것보다 많다. 요약하면 **이 원료는 일반 광석보다 훨씬 다루기 쉽다.**

| 항목 | 이전 설계 (추정) | 이번 설계 (문헌 근거) | 근거 |
|---|---|---|---|
| Ag 회수 상한 | 88 % (12 % Si 내부 봉입) | **97.6 %** (봉입 2.4 %) | [1] TIMA 해리도 + 극한 회수율 |
| 약제 계통 | 소다회 + 규산소다 + **Na₂S 황화** + PAX + 3418A + MIBC | **3418A + AEROFLOAT 242 + MIBC** | [1] ToF-SIMS — 포수제가 금속 Ag 에 직접 흡착 |
| pH | 9.0~9.5 조절 | **조정 없음 (자연 pH)** | [1][2] |
| 부선 속도 | k 0.45~1.2 /min, 러퍼 10 min | 1 min 에 80 %, **3 min 에 90 %** | [1] 3.2절 |
| 급기 Jg | 1.0 cm/s | **0.20~0.35 cm/s** (기계식) | [1] |
| 급광 Cu | 8 wt% (부산물) | **0.013 wt%** (미량 원소) | [1] Table 2 — 리본은 상류에서 제거 |
| 급광 Ag | 0.45 wt% | **0.59 wt%** | [2] assay |
| 정광 품위 | 2.8 wt% Ag | **46.3 wt% Ag** | 복합입자 상한 (§2) |
| 정광 mass pull | 12 % | **1.3 %** | [2] |

**황화 계통이 통째로 사라진 것**이 가장 큰 변화다. Na₂S 가 없어지면서 H₂S 위험,
pH 하한 인터록, ORP 제어 루프, 소다회·규산소다 저장·조제 설비가 함께 없어졌다.
잔티에이트(PAX)도 빠지면서 CS₂ 위험도 사라졌다. 남은 약제는 세 가지뿐이다.

## 2. 정광 품위의 물리적 상한 — 설계의 핵심

Ag 는 순수 입자가 아니라 Si 웨이퍼에 소결된 전면 전극이다. 표면이 소수성이 되어
부상해도 **Si 코어를 함께 끌고 올라간다.**

부상 Ag 1 kg 당 같은 입자 안에 잠긴 맥석을 **1.1 kg** 으로 두면 정광 품위의 상한은

```
1 / (1 + 1.1) = 47.6 wt% Ag
```

이 한 줄이 문헌의 두 최고 품위를 모두 설명한다 — [2] 연속 정광 **48.8 wt%**,
[1] 러퍼+클리너 정광 **46.7 wt%**. 둘 다 47 % 부근에서 멈췄다.

계산에서는 이 맥석을 `Ag_locked_gangue`라는 **보존 성분**으로 급광에 한 번만 넣고,
Ag와 같은 속도분획으로 각 단을 통과시킨다. 단계마다 새 맥석을 더하는 방식이 아니므로
폐회로에서도 질량수지가 보존된다. 이 동반분은 수분 동반(entrainment)과 달리 세척수로
제거되지 않는다. 같은 입자의 일부이기 때문이다. 따라서:

- 클리너를 몇 단 더 붙여도 47 wt% 를 넘을 수 없다. **클리너 증설은 헛수고다.**
- 품위를 더 올리려면 부선이 아니라 **분쇄를 더 하거나(해리도 향상)** 후단 습식제련으로
  가야 한다.
- 1안과 2안의 정광 품위가 46.3 % 대 45.2 % 로 사실상 같은 것도 이 때문이다.
  **품위는 장치가 아니라 원료의 성질로 결정된다.**

거꾸로 보면, 45~46 wt% Ag 정광은 이미 **제련소 직송을 검토할 수 있는 품위**다 [1].

## 3. 왜 부유선별인가

| 방식 | Ag-Si 복합입자에 대한 거동 | 판정 |
|---|---|---|
| 비중선별 | 복합입자 겉보기 비중이 Si(2.33)에 가까워 분리 불가 | ✗ |
| 자력/와전류 | Ag 는 비자성, 미립에서 와전류 분리 하한 미달 | ✗ |
| **부유선별** | **입자 표면의 젖음성으로 분리 — Ag 가 노출되면 Si 코어째 부상** | **✓** |
| 직접 침출 | 가능하나 전량(0.5 t/h)을 HNO₃ 로 처리 → 시약·폐액 부담 과다 | △ (후단) |

부선은 완전 해리를 요구하지 않는다. [1] 의 TIMA 분석에서 **>90 % 해리된 Ag 는 20 %,
>60 % 해리는 61 %** 에 불과한데도 회수율이 97.6 % 나오는 이유가 이것이다. 표면에 Ag 가
조금이라도 드러나 있으면 포수제가 붙고, 붙으면 뜬다.

핵심은 **포수제 화학**이다. AEROPHINE 3418A (sodium diisobutyl dithiophosphinate)는
황화 전처리 없이 금속 Ag 표면에 직접 선택 흡착한다. [1] 의 ToF-SIMS 에서 Ag 전극 위
포수제 신호가 주변 대비 **약 100배**로 나타났다.

## 5. 전처리 — 어트리션 스크러버 (AS-1) · 떨어진 EVA 분리 (ES)

**두 안이 함께 쓰는 공통 설비다.** 로드밀 배출을 묽히기 전에 고농도 그대로 받아
입자끼리 문질러 **입자 표면의 EVA 를 떼어내고**, 희석박스에서 부선 농도로 묽힌 뒤
**떨어진 EVA 를 기포제만 쓰는 부선으로 걷어내고**(§5.8) 조건조로 보낸다.

**역할의 경계.** 이 설비가 하는 일은 **EVA 박리 하나**다. 은(Ag)을 띄우는 것은 뒤의
부선조(§6·§7)가 한다. 그래서 이 설비는 부선 성적이 아니라 두 가지로만 판정한다.

- **부착 EVA 잔류** — 스크럽 뒤, 물에 가라앉은 분획의 EVA(TGA) ≤ 고체의 **0.099 wt%**.
  설계 EVA 2.0 wt% 에서 제거율 **≥ 95.1 %** 다. 정한 값이 아니라 1안 정광 품위 여유에서
  자유 EVA 한도를 뺀 나머지다 (§5.8)
- **미립 생성** — 스크럽 전후 −10 µm 질량분율 증가 ≤ 2 %p

```
박리 → 습식 로드밀 ──(70 wt%)──> AS-1 어트리션 2단 ──> DB-1 희석박스 ──(7 wt%)──> ES-1·ES-2 EVA 부선 ──> CT-1 조건조 → 부선
          │ 청수              └──────────── 바이패스 ────────────┘ ↑ 청수      └─ EVA 산물 → FB-1   ↑ 공정수 보충 (FIC)
          └─ 로드밀 급수도 청수                                    DB-1 희석수 · ES-2 세척수          포수제는 여기부터
```

**물은 두 계통이다.** ES 앞(로드밀 급수 · AS-1 플러싱수 · DB-1 희석수 · ES-2 세척수)에는
포수제가 없는 **청수**, CT-1 부터는 회수 **공정수**를 쓴다. 회수 공정수에 남은 포수제가
ES 로 들어오면 은이 EVA 산물로 뜨기 때문이다 (§5.8, §5.9).

### 5.1 왜 묽히기 전에 문지르는가

어트리션은 교반기가 아니라 **입자끼리 갈리게 하는 장치**다. 갈리려면 입자가 서로
닿아야 하고, 닿는지 여부는 질량분율이 아니라 **체적분율**이 정한다.

| 지점 | 고체 농도 | 고체 체적분율 | 판정 |
|---|---|---|---|
| 로드밀 배출 = 어트리션 | **70 wt%** | **49.6 vol%** | 입자끼리 닿는다 |
| 절대 하한 | 61 wt% | 40 vol% | 이 아래는 어트리션이 아니라 교반 |
| 부선 급광 | 7 wt% | **3.1 vol%** | 100 중 3이 고체 — 아무리 저어도 안 갈린다 |

부선 농도에서는 어떤 장치를 써도 스크러빙이 성립하지 않는다. **묽히는 지점보다
앞에 놓는 것이 이 설비의 전제이자 배치 제약이다.** 로드밀 배출이 70 wt% 에 못
미치면 앞단에 사이클론 탈수를 넣어 올려야 한다 — 상류 설비 계약의 인터페이스 조건이다.

밀 **뒤**에 두는 것은 상류 조건이다. 밀 배출이 이미 70 wt% 라 탈수 없이 스크러빙
농도가 나오고, 분쇄로 드러난 입자 표면의 EVA 를 한 번에 다룬다. 다만 어트리션은
입자가 클수록 잘 듣는다(아래 미분 한계). PAS-1 에서 미분의 박리가 부족하면, 밀 **앞**
mm 급 조각에서 떼는 배치를 대안으로 검토한다.

떼려는 것은 **EVA 봉지재·접착층의 잔막** 하나다. 셀 분획은 모듈에서 EVA 를 벗겨낸
것이지만 입자 표면에 유기 잔막이 남는다.

> [!IMPORTANT]
> **부선 성능 크레딧 없음.** 이 원료(31~75 µm 미분)에서 EVA 가 기계적으로 떨어진다는
> 시험 근거는 아직 없다. 박리 성능은 시험 셀 PAS-1(§5.6)에서 확정한다. 부선 계산은
> 문헌 원료 기준이며, EVA 를 뗀 효과를 회수율·품위·약제에 반영하지 않는다. 대신 전량
> 바이패스 배관과 시험 계획(§5.4)을 설계에 넣었다. **박리가 확인되지 않으면
> 바이패스로 두거나 열분해로 간다.** 바이패스 운전에서도 부착 EVA 가 은 부선에서 뜨면
> 정광 품위가 떨어진다 — 뜨는지는 연쇄 시험 C-1(§5.8)이 가린다.

이번 판에서 바로잡았다.

**어트리션이 계통 전력의 22 % 를 쓴다** (1안 기준 21.53 kW 중 4.77 kW). 떨어진 EVA 를
걷어내는 ES(§5.8)까지 합친 전처리는 **70 %** 다. 박리가 시험으로 확인되기 전인 설비로서는
결코 작지 않다. 어트리션은 원래 전력 집약적인 단위조작이고, 그것이 바이패스와 시험
계획을 설계에 넣은 이유다.

### 5.3 제어변수는 체류시간이 아니라 비에너지다

상용 최소 기종을 사야 했으므로 체적이 남는다. 체류시간이 설계값(10 min)보다 긴 것은
문제가 아니다 — 스크러빙 강도를 정하는 것은 시간이 아니라 **투입 에너지 / 처리량**
이기 때문이다. 처리량이 줄면 같은 회전수에서 t 당 에너지가 오히려 커지므로, VFD 로
주속을 낮춰 목표 범위 1 ~ 6 kWh/t 안에 유지한다.

| 처리량 | 설계 주속 유지 시 | 권장 주속 | 흡수동력 | 비에너지 |
|---|---|---|---|---|
| 0.50 t/h | 4.79 kWh/t | 7.02 m/s (670 rpm) | 2.40 kW | **4.79 kWh/t** |
| 0.30 t/h | 7.99 kWh/t — 범위 초과 | **6.38 m/s** (609 rpm) | 1.80 kW | **6.00 kWh/t** |

주속에는 하한이 있다(6.0 m/s — 이보다 느리면 50 vol% 층이 움직이지 않는다). 따라서
동력도 더는 내려가지 않고, 처리량이 **0.25 t/h** 아래로 떨어지면 최저 주속에서도 과다
스크러빙이 된다. 그 아래에서는 캠페인 운전하거나 바이패스한다. **이 설비에는 최저
유효 처리량이 있다** — 부선 본체에는 없는 제약이다.

### 5.4 시험 계획과 합격 기준

판정은 전부 **EVA 기준**이다. 은을 띄우는 부선 시험은 이 설비의 시험에 넣지 않는다.

| 시험 | 방법 | 판정 |
|---|---|---|
| **T-1** 비에너지-박리 곡선 | **PAS-1**(§5.6)에서 0 / 1 / 2 / 5 / 10 / 20 kWh/t 시료의 부착 EVA(TGA) | 1차 적합 → **E95** (박리 목표 95.1 %). §5.6 판정선으로 AS-1 을 그대로 쓸지 정한다 |
| **T-2** 운전 변수 | PAS-1 에서 주속 · 온도 · 농도를 바꿔 같은 채취 | 곡선이 비에너지 하나로 겹치는가 — 겹치면 비에너지만으로 운전한다 |
| **T-3** 실기 확인 | AS-1 시운전에서 급광·배출 시료의 부착 EVA 비교, 바이패스와 교대 운전 | 실기 비에너지 설정값 확정 · 존치 여부 결정 |
| **T-4** 미립 생성 | 스크럽 전후 −10 µm 질량분율 | **증가 2 %p 이하** |

세 단계(AS-1 → ES → 부선)를 이어 회수수까지 돌리는 **연쇄 시험 C-1** 은 §5.8 에 둔다 —
부착 EVA 가 은 부선에서 뜨는지, 회수수의 포수제가 ES 에서 은을 띄우는지를 가린다.

### 5.5 위험 — 미립 생성

**T-4 가 이 설비의 진짜 위험이다.** 문헌 공정을 따라 탈니(desliming)를 하지 않으므로,
스크러버에서 깨져 나온 Si 미립은 걸러지지 않고 그대로 부선으로 넘어간다. 미립은
걸러내는 것이 아니라 **애초에 만들지 않는 것**으로 관리한다 — 그래서 주속에 상한을
두고 VFD 로 비에너지를 잡는다.

**떨어진 EVA 의 행방.** AS-1 은 EVA 를 입자에서 떼는 데까지 맡는다. 떨어진 EVA
(비중 0.95)는 배출 슬러리에 섞여 나가고, 희석박스 뒤의 ES-1 · ES-2(§5.8)가 걷어낸다.
PAS-1 은 그 설계에 필요한 떨어진 EVA 의 양과 크기를 함께 잰다 (§5.6 P-0 · P-1).

**정지 절차가 안전 항목이다.** 70 wt% 슬러리를 넣은 채로 세우면 굳어서 재기동이
어렵다. 정지 전에 반드시 플러싱수로 희석·배출한다(§10 인터록).

**미분 한계 — 1~6 kWh/t 는 출발점일 뿐이다.** 급광 P80 은 66 µm 로, 어트리션 실적이
쌓인 실리카사(500 µm)보다 한 자릿수 작다. 입자 하나가 싣고 부딪히는 운동에너지는
d³ 로 줄고, t 당 벗겨야 할 표면은 12배로 는다. 모래에서 쓰던 비에너지가 이 원료에서
같은 결과를 낸다는 근거는 없다. 이 원료에서 무엇을 얼마나 떼는지는 PAS-1(§5.6)이
정한다.

### 5.6 파일럿 시험 셀 PAS-1 — 블랙파우더 EVA 박리

AS-1 이 이 원료에서 EVA 를 뗄 수 있는지는 아직 시험 근거가 없다. **PAS-1 은 그
시험을 하는 장비다.** PV 블랙파우더(31~75 µm)의 Si 표면에 붙은 EVA 를 기계적으로 뗄
수 있는지, 뗀다면 **몇 kWh/t 에서, Si 를 얼마나 깨뜨리면서** 떼는지 잰다. §5.4 의
T-1 · T-2 도 이 셀이 맡는다. 은을 띄우는 부선 시험은 하지 않는다. 제작해서 시험하는
장비이므로 설치 전력·물수지에 넣지 않는다. 도면은 DWG-010 (REV C — 판정을 정광 품위 여유에서
나온 박리 목표의 E95 로 바꿨다).

**방식 선정 — 무엇이 표면에 힘을 거는가.**

| 방식 | 박리 기구 | 판정 |
|---|---|---|

| 비드밀 | 비드 충격·압축 | 취성 Si 가 무른 EVA 보다 먼저 깨지고 비드 마모분이 섞인다. **기각** |
| **어트리션** | 입자-입자 마찰 (50 vol% 층) | 각진 Si 모서리가 EVA 를 긁는다 — **채택 (주 가설)**, 단 미분 효율 근거 없음 → 시험 |

같은 70 wt% 슬러리. 흐름 구조가 같으므로 **주속과 비에너지**를 1차 스케일업 변수로
쓴다. 재질(PAS-1 금속 / AS-1 고무 라이닝·우레탄 피복 임펠러)·규모·연속 혼합의 차이는
가정으로 남아 P-6 과 AS-1 시운전(T-3)에서 확인한다. 체적당 동력은 스케일업 변수가
아니다 — 같은 주속에서 v³/D 로 움직여 작은 셀이 크다(29.6 대 20.2 kW/m³).

선정인데, 이것은 모터가 기저속도 이상에서 돌 때만 맞다. PAS-1 은 토크센서를 축 사이에
넣느라 감속기 없이 직결하므로 기저속도가 극수로 정해진다. 4극(60 Hz 1,800 rpm)이면
1,322 rpm 에서 낼 수 있는 출력이 1.10 kW 로 흡수동력의 1.03배에 그치고, 150 % 과부하로도
기동 토크가 11.9 N·m 라 15.4 N·m 에 못 미친다. **6극(1,200 rpm)** 이면 9 m/s 가 약계자
1.10배 영역이라 정격 출력 1.5 kW 가 그대로 나오고(1.40배), 150 % 과부하 17.9 N·m 로 기동하면서
토크센서 정격(20 N·m) 아래에 머문다. VFD 는 중부하 정격으로 하고 토크 제한을 센서 정격
아래로 건다 (50 Hz 현장이면 20 N·m 로 낮춘다). AS-1 은 감속기가 있어 출력 기준 선정으로
충분하다.

**비에너지의 정의.** 순 축동력을 그 순간 조 안에 남은 건조 고체로 나눠 시간 적분한다.

```
E(t) = ∫₀ᵗ [T(τ) − T₀(ω)]·ω(τ) / M_s(τ) dτ
```

T 는 토크센서 실측, T₀ 는 빈 조(공기 중)에서 같은 회전수로 잰 베어링·씰 마찰 토크, M_s 는
시료와 퍼지로 뺀 고체를 모두 뺀 조 안 건조 고체다. **물만 넣은 토크는 빼지 않는다** —
액체 교반 손실도 AS-1 비에너지(슬러리 흡수동력 / 건조 고체)에 들어 있는 몫이다. 전력계는
쓰지 않는다 — 1 kW 급에서는 모터·VFD 손실이 입력의 수십 % 라 kWh/t 가 부푼다. **E = 0 은
투입 직후**다. 투입·혼합(SOP 로 고정) 뒤 첫 시료를 뜨며 E₀ 를 기록하고, 그 뒤의 축 에너지는
가속·감속까지 전부 E 에 넣는다. 적합에는 E − E₀ 를 쓴다.

**부착 EVA 제거율은 질량 기준이다.** X = 1 − m(E)/m(E₀), m = 가라앉은 분획의 질량수율 ×
그 분획의 EVA 분율(TGA, N₂). 떨어진 EVA 가 뜬 분획으로 가면 가라앉은 분획 질량도 주므로
분율만 비교하면 안 된다. TGA 온도 구간은 P-0 에서 기준 EVA 로 정하고, XPS·FT-IR 은 정성
확인에만 쓴다. 판정에 쓰는 E95 는 원점 통과 1차 적합의 k 에서 −ln(1 − 0.951)/k 로 구하고
X ≥ 99 % 인 점은 뺀다.

**바닥 시료는 플러시 바텀 밸브로.** 인출 한도 10 % 에서 시료 몫을 빼면 퍼지로 버릴 수
있는 것은 점당 건조 33 g(슬러리 28 mL)이다. 일반 볼밸브는 DN50 노즐 100 mm 만으로
0.20 L 가 고여 한도의 7배다. 데드 볼륨은 제작 후 실측해 퍼지량(그 이상)을 SOP 에 적고,
퍼지로 뺀 고체도 M_s 에서 뺀다.

**온도를 고정하는 이유.** 교반 동력은 전부 열이 된다. 단열이면 1 kWh/t 에 1.43 K,
20 kWh/t 에서 29 K 오른다 — 시험 온도 간격(10~30 °C)보다 크다. 재킷 없이 돌리면
온도 효과와 비에너지 효과를 가를 수 없다.

**수소 안전.** 배기 30 m³/h 는 실측 전의 설계 기준이다. 첫 정규 회분 전에 P-0A(가스
포집 벤치 시험)와 P-0B(PAS-1 저속 기동)로 발생률을 잰다. 인터록: 배기팬 운전 확인 없으면
교반 기동 금지 · 뚜껑 열림 기동 금지 · H₂ LEL 10 % 경보 · 25 % 교반 정지(배기는 계속) ·
과속·고토크(VFD 토크 제한)·베어링 고온·고진동 정지 · TCU 고장·온도 이탈 경보(그 구간
시료 무효) · 비상정지.

**시험 계획.**

| 단계 | 조건 | 산출물 |
|---|---|---|
| **P-0** 원료 특성 | 교반 전 — TGA(N₂, 기준 EVA 로 온도 구간), **수중 부침 분리**(떨어진 EVA(free) / 부착 EVA), 입도, 성분 분석(Al·Si), 입자 밀도, 초기 수분, 공정수 pH·전도도·경도 | 부착 EVA 가 없으면 스크러빙은 필요 없다 |
| **P-0A** H₂ 벤치 | 원료 소량, 70 wt%, 정치·교반, 가스 포집·계량 압력 등급 용기 | 발생 속도 · pH · 온도 — 배기 한계(12 %/h)를 넘으면 배기부터 키운다 |
| **P-0B** 시운전 회분 | PAS-1 첫 회분, 6 m/s 부터 단계 상승 | 마찰 토크 T₀(ω), 인터록, 배기 유량, 밸브 데드 볼륨, 상·중·하 시료, 9 m/s·최저 액면 와류 — 곡선에 쓰지 않는다 |
| **P-1** 비에너지 곡선 | 7 m/s · 70 wt% · 20 °C, 채취 0/1/2/5/10/20 kWh/t | 1차 적합 → **E95 = −ln(1 − 0.951) / k**, −10 µm 증가, 뜬 EVA 양·크기 |
| **P-1B** 시간 대조 | 벤치, 교반 없음, 21 · 45 · 71 min | 물에 담근 시간만으로 변하는가 (P-2 의 시간 차를 가른다) |
| **P-2** 주속 | 6 · 9 m/s | 곡선이 E 하나로 겹치는가 (겹치면 E 만으로 스케일업) |
| **P-3** 온도 | 10 · 30 °C | 계절 공정수 온도 영향 |
| **P-4** 농도 | 61 wt% (40 vol% 하한), 액면 같게 — 건조 16.1 kg | 로드밀 배출 농도 요구 확인 (인출 11 %, 잠김 0.57 D) |
| **P-5** 재현성 | P-1 × 3회 | E95 신뢰구간, 질량 수지 |
| **P-6** 라이닝 민감도 | 조건부 — 천연고무 판 + 우레탄 피복 임펠러, 고무 마모분 blank | 벽 재질의 영향. 파일럿은 접액 면적/체적이 AS-1 의 1.51배라 더 크게 보인다 |

매 회분 마지막 시료 뒤에는 6 → 7 → 9 m/s 로 올리며 토크-주속 곡선을 적는다 — 실측
동력수가 나오고 E 에는 영향이 없다.

**판정 기준.** 스크럽 뒤 부착 EVA 잔류 **≤ 고체의 0.099 wt%** (설계 EVA 2.0 wt% 에서 제거율
**≥ 95.1 %**), 그 비에너지에서 −10 µm 증가 ≤ 2 %p. 잔류 한도는 1안 정광 품위 여유에서 자유
EVA 한도를 뺀 나머지다 (§5.8). 잠정 90 % 로는 정광이 보증 품위(40 wt%)에 못 미친다. P-0 에서
잰 함량이 설계와 다르면 목표 제거율을 1 − 0.099 % / 실측 함량 으로 다시 잡는다.

**AS-1 로 옮기기 — 회분 2.70 kWh/t 가 기준선이다.** 회분에서는 모든 입자가 같은
에너지를 받지만, 완전혼합조 2기 직렬에서는 적게 받는 입자가 생긴다. 1차 거동이면 95.1 %
제거에 드는 연속 비에너지는 회분의 **2.33배**(1기 6.39배, 3기 1.72배)다 — 목표가 높을수록
적게 받는 입자의 벌이 커진다 (90 % 에서는 1.88배). 이 환산은 1차 거동, 이상적 완전혼합조,
PAS-1 의 속도상수가 AS-1 에서도 유지된다는 가정 위에 서며 P-1·P-2 적합도와 AS-1
시운전(T-3)으로 확인한다. AS-1 이 낼 수 있는 비에너지를 이 배수로 나눈 값이 P-1 E95 의
합격선이다.

| P-1 의 E95 (회분) | AS-1 판정 |
|---|---|
| ≤ **2.70 kWh/t** | **그대로** — VFD 상한 7.68 m/s 에서 최대 처리량 6.29 kWh/t |
| ≤ 4.35 kWh/t | **모터만 2.2 → 4.0 kW** (9 m/s). 축 Ø60 은 1.68배로 유지 |
| ≤ 7.25 kWh/t | 모터 교체 + 평균 처리량 0.30 t/h 상한 — 최대 처리량에는 셀 추가 |
| > 7.25 kWh/t | AS-1 로는 안 된다 — 셀 추가 또는 열분해 |

2·3행은 9 m/s 에서 미립 기준을 지킬 때만 성립한다(P-2). 9 m/s 를 쓸 수 없으면 ≤ 2.70 은
그대로, ≤ 4.50 이면 현 모터 · 평균 처리량 상한(10.48 kWh/t), 그 위는 셀 추가 또는 열분해다.
2안을 택하면 정광이 작아 품위 여유도 작으므로 목표가 97.1 % 로 오르고 판정선이 한 칸씩
내려간다.

**확인이 필요한 가정.** 동력수 0.8 (모터 예비 선정용 — 토크 실측으로 대체), 임펠러 조립체
질량 2.2 kg (제작도 후 실측 질량·허브·축 단차·커플링·토크센서·베어링 강성·부가질량으로
임계회전수 재검산, 비틀림 고유진동수 확인), EVA 강도 1 MPa (벌크 하한, 계면 강도 아님),
박리 목표 95.1 % (부착 EVA 가 은 부선에서 전부 뜬다는 보수 가정 — C-1 에서 확인), 1차 거동,
재킷 U 350 W/m²K, 수소 발생률 (P-0A·P-0B 전에는 12 %/h 견딤만 안다). 단위 테스트는 계산 구현을 확인할 뿐, 이 물리 가정들은 PAS-1 시험으로 확인한다.

### 5.7 수소 — Al 이 물과 반응한다

급광의 10 wt% 가 후면 전극 Al 이다. 중성의 물에서 Al 은 산화막으로 보호되지만,
**어트리션은 바로 그 막을 긁어내는 장치**다. 2Al + 6H₂O → 2Al(OH)₃ + 3H₂ 로 Al 1 kg 이
H₂ 1.25 Nm³ 를 낸다. 반응 속도는 입도·온도·pH·표면 상태에 따라 자릿수가 달라
문헌값으로 정할 수 없다 — PAS-1 P-0A · P-0B 에서 잰다.

최대 처리량에서 급광 Al 은 50 kg/h 다. 그 1 % 만 반응해도 H₂ 0.62 Nm³/h 이고, 이를
폭발하한(4 vol%)의 25 % 아래로 묶으려면 **62 m³/h** 의 배기가 필요하다 (예시이지
설계값이 아니다). **AS-1·DB-1 에 덮개를 씌우고 비스파크 팬 EF-1 로 국소배기한다.** 배기
덕트의 수소 검지기 AT-008 이 LEL 10 % 에서 경보, 25 % 에서 AS-1 급광을 바이패스하고
플러싱을 시작한다 — 배기는 멈추지 않는다. 배기량은 P-0A · P-0B 발생률로 확정한다. 소형 팬
한 대 규모라 비용이 아니라 **빠뜨리지 않는 것**이 문제다. 알칼리성 분산제는 Al 반응을
빠르게 하므로 전처리 계통에 쓰지 않는다.

**하류도 수소원이다.** 어트리션으로 드러난 Al 면은 AS-1 을 나와서도 반응한다 — DB-1 · ES ·
CT-1 · 부선조가 모두 H₂ 를 낸다. ES 셀은 덮개가 없고 부선 공기가 쓸어 간다(§5.8). **CT-1 은
덮지 않거나 상부 배기를 둔다** — 교반조 헤드스페이스에 모이지 않게 한다. P-0A 에서 박리
직후부터 시간에 따른 발생률 감소(반감 시간)를 재서, 하류 어느 기기까지 배기가 필요한지 정한다.

### 5.8 떨어진 EVA 분리 — ES-1 · ES-2

AS-1 이 입자에서 떼어 낸 EVA 는 배출 슬러리에 섞여 나간다. 비중 0.95 의 소수성
박편이라 그대로 두면 부선조에서 포수제 없이도 떠 정광으로 간다. **ES 는 희석박스 DB-1
뒤, 조건조 CT-1 앞에서 그것을 걷어낸다.** 두 안 공통 설비다. 도면은 DWG-011.

**역할의 경계.** 이 계통이 하는 일은 떨어진 EVA 를 흐름에서 걷어내는 것 하나다. EVA 를
입자에서 떼는 것은 AS-1, 은을 띄우는 것은 부선조가 한다. 은은 건드리지 않고 부선조로
보낸다 — 그래서 **포수제(CT-1) 앞에 두고 기포제만 쓴다.** 포수제가 없으면 Si·Al·Ag
표면은 물에 젖어 펄프에 남고, 본래 소수성인 EVA 만 기포에 붙는다. 판정은 둘이다.

- **부선 급광의 자유 EVA** ≤ 고체의 0.1 wt% (최대 처리량에서 0.50 kg/h)
- **EVA 산물로 새는 Ag** ≤ 0.3 % — 부선조(1안) 자신의 미광 손실만큼

```
DB-1 (7 wt%) → ES-1A → ES-1B ─미광→ CT-1 조건조 → 부선
                 └거품→ ES-2 ─거품→ EVA 산물 → FB-1 탈수 백 → 반출
                          └미광 ─┐
              FB-1 여액 ──────┴→ P-001 → ES-1 급광
```

**방식 선정 — 무엇으로 가르는가.**

| 방식 | 근거 | 판정 |
|---|---|---|
| 중력 부상 (스키밍조) | 비중차 0.05 — 설계 박편(21 µm)이 스스로 뜨는 속도 0.041 m/h. 7.14 m³/h 를 받으려면 수면적 **173 m²** | 기각 |
| 사이클론 | EVA 는 물보다 가벼워 전량 월류로 가지만 분급점 아래 Si 미립도 함께 간다 — 가르지 못하고 섞어 옮긴다 (탈니를 겸해 문헌 공정도 바뀐다) | 기각 |
| 체 | 떨어진 EVA 는 원 입자(31~75 µm)의 면보다 작다 | 기각 |
| **부선 (기포제만)** | **표면 성질로 가른다.** 0.8 mm 기포는 9.1 cm/s 로 올라 박편이 스스로 뜨는 속도의 **7,900배** | **채택** |

**설계 EVA — 잔막 두께 하나로 정한다.** 셀 양면에 5 µm 의 EVA 잔막이 남았다고 보면
(잠정 — P-0 TGA 로 교체) 함량은 **2.0 wt%** (웨이퍼 180 µm 기준)이고, 떨어진 박편은
두께 5 × 폭 31 µm(원 입자의 면 — 시험 분획 하한) → 등체적 **20.9 µm** 다. EVA 는 급광
조성표 밖이다 — 광물 0.50 t/h 위에 최대 10.0 kg/h 가 얹힌다. AS-1 이 박리 목표(95.1 %)대로
떼면 최대 처리량에서 **9.50 kg/h** 가 ES 로 온다. 속도상수는
기포-입자 충돌로 구한다 — k = 1.5·Ea·Ec·Jg/db. 부착 효율 Ea 0.124 는 Ag 러퍼 FC-201
에서 역산한 값(계산서 §8.1)을 그대로 쓴다. 설계 박편은 k = 0.63 /min.

**얼마나 걷어야 하나 — 정광 품위 여유를 나눠 쓴다.** 부선조로 넘어간 EVA 는 떨어진
것이든 입자에 붙은 것이든 전량 정광으로 간다고 본다 (보수 — 부착 EVA 가 은 부선에서
뜨는지는 C-1 에서 확인한다). 보증 품위(40 wt%)까지의 여유에서 이 계통이 넘겨도 되는
자유 EVA 한도 0.1 wt% (0.50 kg/h)를 빼면 AS-1 이 남겨도 되는 부착 EVA 가 나오고, 설계
EVA 로 나누면 **AS-1 의 박리 목표**가 된다. 목표는 정한 값이 아니라 여유에서 나온다.

| 안 | 설계 정광 | 보증까지의 여유 (EVA) | 자유 EVA 한도 (ES) | 부착 EVA 잔류 한도 (AS-1) | 박리 목표 |
|---|---|---|---|---|---|
| **1안** — 목표를 정한다 | 6.36 kg/h @ 46.3 wt% | 0.994 kg/h | 0.50 kg/h | **0.494 kg/h (0.099 wt%)** | **95.1 %** |
| 2안 | 6.08 kg/h @ 45.2 wt% | 0.790 kg/h | 0.50 kg/h | 0.290 kg/h (0.058 wt%) | 97.1 % |

잠정값 90 % 였다면 부착 EVA 1.00 kg/h 가 남아, 자유 EVA 한도와 함께 뜨면 1안 정광이
37.4 wt% 로 보증에 못 미친다. 2안을 택하면 정광이 작아 여유도 작으므로 97.1 % 가 필요하다.
9.50 kg/h 에서 이 계통의 요구 제거율은 **94.7 %** 다.

**설계 — 2안 동체를 그대로 쓴다.**

| 항목 | ES-1 EVA 러퍼 | ES-2 EVA 클리너 |
|---|---|---|
| 동체 | **Ø1,000 × 1,300 mm × 2셀 직렬** (FC-202 와 같음) | **Ø400 × 650 mm** (FC-203 과 같음) |
| 거품층 | 50 mm — 회수 위주 | 150 mm + 세척수 0.05 m³/h — 배수 위주 |
| 로터 / 모터 | Ø350 mm, 290 rpm / 4.0 kW × 2 | Ø140 mm, 610 rpm / 0.37 kW |
| 설계 Jg / Sb | **0.90 cm/s** / 67.5 1/s | 0.60 cm/s / 45.0 1/s |
| 중공축 보어 / 외경 | **Ø32** / Ø60 mm (FC-202 는 Ø20) | Ø10 / Ø50 mm |
| 체류시간 (최대 / 평균) | 13.3 / 22.3 min (2셀 합) | 8.1 / 13.5 min |

부대 설비는 송풍기 B-001 (71.9 m³/h @ 25 kPa, 1.5 kW), 순환 펌프 P-001 (0.38 m³/h,
0.37 kW), 탈수 백 FB-1 (1 m³ × 2기 교대 — 건조 EVA 266 kg/백, 27 시간마다 교체,
케이크 함수 66 %)이다.

**새로 설계할 회전체가 없다** — 다른 것은 운전 조건이다. 미립 EVA 를 잡으려고 급기를
Ag 셀(0.20~0.34 cm/s)보다 높게 두고, 그 공기에 맞춰 중공축 보어만 키웠다(외경 Ø60
그대로, 임계회전수비 1.66). Ag 셀이 급기를 낮게 두는 이유인 동반 혼입은 클리너가
맡는다 — 클리너 미광을 ES-1 급광으로 되돌리면 러퍼 거품에 딸려 간 광물이 결국
부선조로 간다.

**성능 (설계 EVA).**

| 처리량 | 자유 EVA 제거율 | 부선 급광으로 | Ag → EVA 산물 | EVA 산물 |
|---|---|---|---|---|
| 최대 0.50 t/h | **95.6 %** (요구 94.7 %) | 0.42 kg/h (0.082 wt%) | **0.062 %** (한도 0.3 %) | EVA 9.08 + 광물 0.31 kg/h |
| 평균 0.30 t/h | 98.3 % | 0.10 kg/h (0.032 wt%) | 0.062 % | EVA 5.60 + 광물 0.19 kg/h |

Ag 손실은 전부 수분 동반분이다. **계산에 없는 위험은 EVA 가 덜 떨어진 복합입자다** —
입자에 EVA 가 남아 있으면 포수제 없이도 뜰 수 있고, 거기 Ag 가 붙어 있으면 EVA 산물로
샌다. S-1 의 거품 Ag 로만 알 수 있다. ES 손실까지 넣은 **계통 Ag 회수율은 1안 99.64 %,
2안 93.06 %** 다 — 성능 보증값은 이 값으로 적는다 (§11).

**포수제가 들어오면 — ES 앞을 청수로 하는 이유.** ES 는 체류가 길고(러퍼 13 min) 공기가
많다. 은이 뜨는 속도를 정상 부선(같은 약제, 실기 환산)의 비율로 두고 계산하면:

| ES 안에서 은이 뜨는 속도 (정상 부선 대비) | 0 (설계) | 0.1 % | 0.3 % | 1 % | 3 % |
|---|---|---|---|---|---|
| EVA 산물로 새는 Ag | 0.062 % | 0.19 % | **0.58 %** | **3.4 %** | **18 %** |

정상 부선 속도의 **0.17 %** 만으로 한도(0.3 %)에 닿는다. 회수 공정수(농축조 월류 · 여액)에
포수제가 얼마나 남는지, 그 농도에서 은이 얼마나 뜨는지는 아직 모른다 — 그래서 **ES 앞은
청수로 한다** (§5.9). 확인은 S-1W 와 연쇄 시험 C-1 에서 하고, 운전 중에는 EVA 산물 Ag 를
교대마다 분석해 감시한다.

**작은 EVA 가 전부를 정한다.** 충돌 효율이 (박편 지름 / 기포 지름)² 에 비례하므로
속도상수도 거의 크기의 제곱으로 준다.

| EVA 등체적 지름 | 5 µm | 10 µm | 15 µm | 20 µm | 30 µm | 45 µm |
|---|---|---|---|---|---|---|
| 회수율 (최대 처리량) | 13 % | 60 % | 86 % | 95 % | 99 % | 99.8 % |

잔막 두께를 1 ~ 12.5 µm 로 바꿔도 한도 안이다 — 두꺼우면 EVA 가 많지만 박편도 커서
잘 뜬다 (계산서 §2.8). **위험은 두께가 아니라 박편이 원 입자 면보다 잘게 찢어지는
경우다.** 그래서 PAS-1 P-1 이 뜬 EVA 의 크기를 재고, 잘게 찢어진 EVA 가 많으면 기포를
줄이는 쪽(충돌 효율이 기포 지름의 제곱에 반비례)을 검토한다.

**판정 — S-1 회분 t90.** 회분 부선(기포제만)에서 자유 EVA 가 90 % 뜨는 시간을
−ln(1−R) 대 t 의 원점 통과 직선으로 구한다. 회분 속도상수는 실기에서 0.8배로 본다
(Ag 러퍼와 같은 스케일업).

| S-1 회분 t90 (자유 EVA) | ES 판정 |
|---|---|
| ≤ **3.25 min** | **그대로** — 최대 처리량에서도 요구 94.7 % |
| ≤ 5.41 min | 평균 0.30 t/h 까지 그대로 — 최대 처리량은 셀 1기 추가 |
| ≤ 6.11 min | 같은 동체 셀 1기 추가 (ES-1 3셀) — 배치 공간을 비워 둔다 |
| > 6.11 min | 기포 부선으로는 비효율 — 기포를 줄이는 방식을 검토하거나 정광 품위 보증을 다시 정한다 |

한계는 설계 EVA 함량(2.0 wt%) 기준이다. P-0 함량이 다르면 `EVA_RESIDUAL_FILM_UM` 을
고쳐 다시 계산한다.

| 시험 | 방법 | 판정 |
|---|---|---|
| **S-1** 회분 EVA 부선 | PAS-1 을 E95 에서 한 회분 더 돌린 시료, 청수, 7 wt%, MIBC 30 ppm, 포수제 없음. 거품을 0.5 · 1 · 2 · 4 · 8 min 에 나눠 받는다. 기포제 종류·농도, 공기량, 시간, 고체 농도, pH, 온도를 적는다 | 판정 둘 — 자유 EVA t90 → 위 판정표, 거품으로 간 Ag ≤ 급광 Ag 의 0.3 % (거품 품위가 아니라 질량 수지: Σ 거품 질량 × Ag 품위 / 급광 질량 × Ag 품위) |
| **S-2** 크기별 회수 | S-1 거품·미광의 EVA 입도 | 위 크기별 표와 비교해 Ea 역산 — 박편이 설계보다 잘면 여기서 드러난다 |
| **S-1W** 회수수 | S-1 과 같되 물을 C-1 에서 나온 회수수로 (포수제 · MIBC 잔류) | EVA 산물 Ag 가 청수 S-1 과 같은가 — 늘면 ES 앞 청수(W1) 유지, 같으면 W4 검토 (§5.9) |
| **S-1H** 고농도 | S-1 을 20 wt% 로 | Ag 손실 ≤ 0.3 % 이고 t90 이 판정선 안이면 W3 (§5.9) |
| **S-3** 실기 확인 | ES 시운전, 급광·미광·EVA 산물 채취 (수동 바이패스는 정광을 따로 받으며) | 부선 급광 자유 EVA ≤ 0.1 wt%, EVA 산물 Ag |

**연쇄 시험 C-1 — 세 단계를 잇는다.** 지금까지의 시험은 단계별로 따로다 (박리는 PAS-1,
EVA 부선은 S-1, 은 부선은 원료로만). 그 사이에서만 드러나는 두 가지 — **부착 EVA 가 은
부선에서 뜨는가, 회수수의 포수제가 ES 에서 은을 띄우는가** — 를 잠금 사이클(locked
cycle)로 가린다.

| 순서 | 방법 | 보는 것 |
|---|---|---|
| 1 | PAS-1 을 E95 에서 돌린다 | 부착 EVA 잔류 (≤ 0.099 wt%) |
| 2 | 그 산물로 S-1 (기포제만) — 첫 사이클은 청수, 다음부터 앞 사이클의 회수수 | EVA 산물의 Ag · 질량 |
| 3 | S-1 미광에 포수제 · 촉진제 (CT-1 조건) → 1 L 러퍼 · 클리너 | 정광 Ag · EVA · Si 품위, 미광 Ag |
| 4 | 1~3 을 3~5 사이클, 회수수를 이어 쓴다 | 사이클마다 위 항목 + 회수수 잔류 포수제(용존 유기물) · MIBC — 정상상태에 이르는가 |

판정: 정상상태 사이클의 정광 ≥ 40 wt% 이고 EVA 산물 Ag ≤ 0.3 % 면 박리 목표와 물 계통을
확정한다. 정광의 EVA 가 부착 EVA 잔류보다 뚜렷이 적으면 부착 EVA 가 뜨지 않는 것이다 —
목표를 낮출 수 있다. 사이클이 갈수록 EVA 산물 Ag 가 오르면 회수수의 포수제가 원인이다 —
W1(ES 앞 청수)을 지킨다.

**기포제는 두 곳에서 넣는다.** MIBC 물 기준 30 ppm 을 ES-1 급광(청수)에 넣으면 물을 따라
부선조까지 간다 — ES 거품으로 빠지는 물은 급광의 1.3 % 다. CT-1 에서는 보충수(공정수) 몫만
더 넣는다 (트림). 공정수에 남은 MIBC 만큼 줄이며 거품 상태로 조정한다 (§9).

**수소.** ES 셀은 거품을 긁어내야 하므로 덮개가 없다. 대신 부선 공기가 거품 위를 쓸고
나간다. 설계 급기 53.6 m³/h 가 H₂ 를 1 vol% 아래로 묶는 한계는 급광 Al 의
**0.86 %/h** 반응이다. §5.7 의 예시(1 %)가 전부 ES 안에서 일어나면 거품 위 1.1 vol% —
폭발하한의 29 % 다. 셀 상부 검지기 AT-017 을 AT-008 과 같은 경보·동작점으로 둔다.

**전력 — 걷어내는 설비가 부선 본체보다 크다.** ES 설치 전력 **10.24 kW** (ES-1 8.0 +
ES-2 0.37 + B-001 1.5 + P-001 0.37). 전처리 계 15.01 kW, 1안과 합치면 21.53 kW 로
**ES 가 계통의 48 %** 를 쓴다 — 부선 본체(6.52 kW)보다 크다. EVA 를 떼면 걷어내는
설비가 따라온다. 줄이는 대안은 ES 를 20 wt% 에서 돌리고 CT-1 에서 공정수로 7 wt% 까지
묽히는 것이다 — 슬러리가 32 % 로 줄어 셀이 작아지고, ES 앞 청수도 1/4 로 준다 (W3, §5.9).
대신 같은 거품 물에 실려 가는 광물이 3.3배가 되므로(Ag 손실 0.062 → 0.22 %), S-1H 에서
Ag 손실을 확인한 뒤에만 택한다.

**ES 가 서면 AS-1 급광을 멈춘다.** ES 를 건너뛰고 부선을 계속 돌리면 떨어진 EVA 9.5 kg/h
가 정광으로 가 품위가 **18 wt%** 로 떨어지고, 정광 농축조(TK-102)의 재고까지 섞인다.
그래서 ES 송풍기·ES-1 구동이 서면 인터록이 AS-1 급광(로드밀 배출)을 끊고, ES 미광 밸브를
닫아 셀이 머금게 한다 — 부선조는 급광 정지 순서로 선다 (§10 인터록 9). AS-1 은 급광만
끊기고 계속 돈다 (서면 굳는다). DB-1 → CT-1 바이패스는 **수동 전용**이고, 쓸 때는 정광을
TK-102 에 넣지 않고 따로 받는다.

### 5.9 물 계통 — 청수와 공정수

**ES 앞은 청수, CT-1 부터 공정수.** 회수 공정수(농축조 월류 + 미광 여액)에는 포수제
(3418A · 242)와 MIBC 가 남아 있다. 이 물을 DB-1 희석수로 쓰면 "ES 는 포수제 앞에서 기포제만"
이라는 원칙이 물 계통에서 깨진다 — 정상 부선 속도의 0.17 % 만으로 EVA 산물 Ag 가 한도에
닿는다 (§5.8). 그래서 물을 두 계통으로 가른다.

| 계통 | 쓰는 곳 | 근거 |
|---|---|---|
| **청수** (포수제 없는 물) | DB-1 희석수 · ES-2 세척수 · AS-1 플러싱수 | ES 로 들어가는 물 — 포수제 금지 |
| **공정수** (회수수) | CT-1 보충수 · 1안 세척수 · 2안 클리너 세척수 · 약제 희석수 | 포수제가 있어도 되는 자리 (CT-1 뒤) |
| 상류 인터페이스 | **로드밀 급수도 청수** (공정수 금지) | 로드밀 배출의 물은 그대로 AS-1 · ES 로 들어온다 |

**계통 물수지 (W1 기준, m³/h).**

| 흐름 | 1안 최대 | 1안 평균 | 2안 최대 | 2안 평균 |
|---|---|---|---|---|
| 로드밀 배출과 함께 (상류 청수) | 0.21 | 0.13 | 0.21 | 0.13 |
| **ES 앞 청수** (DB-1 희석 + ES-2 세척수) | **6.37** | **3.82** | **5.99** | **3.59** |
| DB-1 설정 (ES 급광 농도) | 7.0 wt% | 7.0 wt% | 7.4 wt% | 7.4 wt% |
| ES 미광 → CT-1 | 6.57 | 3.93 | 6.19 | 3.71 |
| **CT-1 보충수** (공정수) | **0.14** | **2.86** | 0 | 0 |
| 세척수 (1안 부선조 · 2안 클리너, 공정수) | 2.81 | 2.81 | 0.25 | 0.25 |
| 공정수 탱크 유입 (농축조 월류 + 미광 여액) | 9.37 | 9.52 | 6.30 | 3.88 |
| 케이크 (정광 · 미광 · EVA) | 0.16 | 0.10 | 0.16 | 0.10 |
| **블리드** (처리) | **6.43** | **3.85** | **6.05** | **3.63** |
| **신수** | **6.37** | **3.82** | **5.99** | **3.59** |

**ES 앞에 넣은 청수는 전부 블리드가 된다.** 그 물은 부선 뒤 공정수로 나오지만 ES 앞으로
되돌릴 수 없고, 공정수 사용처(CT-1 보충수 · 세척수)는 공정수 안에서 돈다. 그래서 블리드 =
로드밀 물 + ES 앞 청수 − 케이크 물이다. 공정수를 DB-1 에 쓰던 이전 배치(신수 1.03, 블리드
0.89 m³/h)보다 신수와 블리드가 각각 약 6 배다. 용존물 축적을 막는 최소 블리드(농축조
월류의 10 %)보다 크므로 그것이 블리드를 정하지 않는다. **블리드에는 포수제 · MIBC · 용존
Al 이 남아 있어 방류 전에 처리하거나 인수처를 정해야 한다.**

**부선 급광은 CT-1 이 맞춘다.** DB-1 은 ES 급광만 7 wt% 로 잡는다. 1안 부선조는 급광 유량이
flux 로 고정이라(§6) 모자라는 물을 **CT-1 보충수**(공정수, LIC-110)로 채운다 — 최대 0.14,
평균 2.86 m³/h. 정광 여액(0.008 m³/h)만 첫 단으로 직송하고, 미광 여액(0.46 m³/h)은 공정수
탱크로 보낸다 — 미광 여액까지 CT-1 로 돌리면 최대 처리량에서 급광이 4.8 % 넘친다. 2안은
순환류(스캐빈저 정광 + 클리너 미광)가 러퍼에 물을 보태 ES 미광이 러퍼 소요보다 많다 —
물은 뺄 수 없으므로 DB-1 설정을 7.4 wt% 로 올려 러퍼를 7 wt% 에 둔다.

**대안 — 신수와 블리드를 줄이려면** (최대 처리량).

| 경우 | ES 급광 | 신수 | 블리드 | ES Ag 손실 | 추가 설비 | 택하는 조건 |
|---|---|---|---|---|---|---|
| **W1 기준** — ES 앞 청수 | 7.0 wt% | 6.37 | 6.43 | 0.062 % | 청수 헤더만 | 기준 — 확인 없이 성립 |
| W3 ES 20 wt% | 20 wt% | 1.61 | 1.67 | 0.216 % | 없음 (CT-1 보충수 4.90) | S-1H — Ag 손실 · t90 |
| W4 GAC — 공정수에서 포수제를 빼 ES 앞에 | 7.0 wt% | 0.84 | 0.89 | 0.062 % | 활성탄 1.6 m³ (EBCT 15 min) | S-1W · C-1 — 처리수로 EVA 산물 Ag 가 청수와 같은가 |

(1안 기준 m³/h. 2안은 W1 5.99 / 6.05, W3 1.61 / 1.67, W4 0.53 / 0.58.) W3 은 거품 물(m³/h)이
급기와 거품층으로 정해진다고 보면 같은 물에 실려 가는 광물이 늘어 Ag 손실이 3.5배가 된다 —
한도 안이지만 여유가 준다. W4 는 신수 · 블리드가 최소 블리드 수준으로 돌아가지만 활성탄이
MIBC 도 빼므로 ES 기포제는 전량 새로 넣어야 하고, 활성탄 소모량은 C-1 에서 잰 잔류
포수제가 정한다. **결정은 S-1W · S-1H · C-1 결과로 한다** — 그 전까지는 W1 이 기준이다.

**감시.** EVA 산물(FB-1) Ag 는 교대마다 분석한다 — 오르면 포수제가 ES 로 새는 신호다
(청수 · 공정수 헤더 교차 연결, 약제 역류, 로드밀 급수). 두 헤더 사이에는 교차 연결을 두지
않는다.

## 6. 1안 (주설계) — 세척수 bias 연속 부선조 1단

### 6.1 왜 이 형식인가

[2] 의 연속 실증은 기계식 셀이 아니라 **세척수(wash water)로 양(+)의 bias 를 거는
수직 부선조**에서 수행됐다. 논문이 장치 형식을 명시하진 않았으나, 인용 문헌
(Reflux Flotation Cell 계열)과 운전 변수(스파저, 세척수 flux, bias, 기액 체류시간,
경사판)로 볼 때 RFC 계열 장치로 판단된다.

이 장치의 설계 변수는 **체적이 아니라 단면적 기준 flux** 다.

```
Jf = Q_feed / A     급광 flux      2.0 cm/s
Jg = Q_air  / A     기체 flux      2.0 cm/s
Jw = Q_wash / A     세척수 flux    0.81 cm/s
Jb = Jw - Jo        bias flux      양수 = 거품층 하향 순유량
```

거품층을 아래로 지나는 순 하향류가 동반 맥석을 씻어내리므로, **기계식 셀의 러퍼+클리너
2단이 하는 일을 1단에서 해낸다.** 실증에서 맥석 회수율은 0.64 % 로 회분식 기계식
셀(2.2 %)의 약 1/3.5 였다.

### 6.2 스케일업 — flux 상사

실증 flux 를 그대로 두고 **단면적만 처리량에 비례해 키운다.** 그러면 기액 체류시간과
bias 조건이 보존되므로, 실증에서 확인된 분리 성능이 그대로 이월된다.

### 6.6 탈수 라인 (필터프레스)

부선 산물은 둘 다 슬러리다. 정광은 제련·침출로 보내려면 운반 가능한 케이크여야 하고,
미광은 건식 적치해야 하며 실은 그쪽이 물량이 훨씬 크다. 두 흐름 모두 **농축조 →
필터프레스** 순으로 처리한다. 농축조는 물의 90 %를 값싸게 뽑아내는 단계이고,
필터프레스는 남은 물을 압착으로 짜내는 단계다.

| 항목 | FL-101 정광 | FL-102 미광 |
|---|---|---|
| 급광 고체 | 6.36 kg/h | 493.64 kg/h |
| 급광 농도 (농축조 U/F) | 40 wt% | 45 wt% |
| 여과판 | 470 × 470 mm × 6 챔버 | 800 × 800 mm × 43 챔버 |
| 여과 면적 | **2.25 m²** | **46.78 m²** |
| 사이클 | 480 min (3 회/일) | 120 min (12 회/일) |
| 케이크 함수율 | 18 wt% | 22 wt% |
| 케이크 생산량 | 7.8 kg/h | 632.9 kg/h |

두 기기는 **서로 다른 기준으로 규격이 정해진다.** 미광기는 사이클당 담아야 할
케이크 부피가 챔버 총용적을 결정하고(702 L), 여기서 판 크기와 매수가 나온다.
정광기는 계산상 필요한 면적이 0.1 m² 도 되지 않아 어떤 여과 속도 기준으로도
규격이 잡히지 않는다 — **상용 최소 기종**(470 mm × 6 챔버)이 하한이며, 실제로는
8 시간에 한 번만 돌리고 케이크가 얇게 깔릴 뿐이다. 그래도 정광을 미광기와 섞을 수는
없으므로 별도 소형기를 둔다. Ag 46.3 wt% 짜리 케이크와 18 g/t 짜리 케이크를 같은
여포에 통과시키면 교차오염 손실이 회수한 은보다 클 수 있다.

**정광 여액**(0.008 m³/h)은 공정수 탱크를 거치지 않고 **부선 회로의 첫 단으로 직접
되돌린다** (1안은 CT-1 조건조 = FC-101 급광, 2안은 FC-201 러퍼 급광). 여포를 빠져나온
미립자가 여액에 남아 있는데, 공정수로 희석해 버리면 그 안의 Ag 를 그대로 잃는다.
첫 단으로 돌리면 한 번 더 부선 기회를 얻는다. **미광 여액**(0.46 m³/h)은 미광 품위라
Ag 가 거의 없어 공정수 탱크로 보낸다 — 1안 부선조는 급광 유량이 flux 로 고정이라, 미광
여액까지 CT-1 로 돌리면 최대 처리량에서 급광이 4.8 % 넘친다.

### 중공축 급기 — 스파저를 쓰지 않는 이유

급기는 셀 바닥의 별도 스파저가 아니라 **로터 축 내부**로 넣는다. 축 상단
로터리 조인트 → 축 보어 → 로터 허브의 분산구 8개 순으로 흘러, 공기가 나오는
바로 그 자리에서 로터 날개가 기포를 부순다. 기포가 잘고 균일해지고, 셀 바닥에
막힐 부품이 없어진다 — 태양광 셀 분쇄물처럼 미분이 많은 급광에서는 스파저
공극 막힘이 실제 운전 리스크다.

**보어는 유속으로, 외경은 진동으로 정해진다.** 보어는 축 내부 공기 유속을
18 m/s 이하가 되도록 표준 계열에서 고른다 — 너무 가늘면 압력손실이 커진다.
외경은 서비스계수 2.0을 적용한 비틀림 강도와 외팔보 예비 로터동역학 중 큰 쪽으로
정한다. 로터 집중질량과 축 분포질량을 포함한 1차 굽힘 위험속도비 ≥1.5 및 정적 처짐
≤5 mm를 동시에 확인했으며, 세 셀 모두 **로터동역학**이 외경을 정했다.
전단응력은 허용치 40 MPa보다 충분히 낮다.
부선기 축은 길고 가늘어 **강도보다 진동이 먼저 한계**가 된다.

이는 제작 전 예비검산이다. 최종 베어링 스팬, 축단 지지조건, 로터 불평형과 키홈
응력집중이 확정되면 회전체 업체의 위험속도·밸런싱 계산으로 다시 승인해야 한다.

송풍기 토출압은 펄프 수두(최대 11.44 kPa)에 축 보어·조인트·허브 토출구 손실
(최대 6.80 kPa)을 더하고 운전 여유를 두어 **25 kPa**로 잡았다. 별도 스파저가
없으므로 스파저 압력손실 15 kPa는 적용하지 않았다.

### 탈수 라인

미광은 TK-201 Ø2.5 m, 정광은 TK-202 Ø1.0 m에서 각각 농축한 뒤 전용
필터프레스로 보낸다.
FL-201 정광기 470 mm × 6 챔버 (2.25 m², 케이크 7.4 kg/h), FL-202 미광기
800 mm × 43 챔버 (46.78 m², 케이크 633.2 kg/h). **정광 여액(0.008 m³/h)은 FC-201 러퍼
급광으로 직접 순환한다** — 여포를 빠져나온 미립 Ag 에 한 번 더 부선 기회를 주기
위해서다. 미광 여액(0.46 m³/h)은 공정수 탱크로 간다. 농축조 월류 5.84 m³/h와 여액을

### 러퍼와 스캐빈저를 같은 규격으로 수정한 이유

첨부 문헌은 3분 러퍼 시험과 러퍼-클리너 시험만 수행했으며, 스캐빈저 단독 시험이나
8분 체류시간의 실증 근거는 제시하지 않았다. 따라서 이전 설계의 Ø1,050 × 1,450 mm
스캐빈저는 검증값이 아니라 보수적 가정이었다. 기본설계에서는 제작비·예비품·정비성을
고려해 러퍼와 스캐빈저 동체, 로터, 구동부 및 중공축을 공용화했다.

스캐빈저는 러퍼 미광에 남은 지연부선 분획을 회수하므로 운전조건은 다르다. 거품층을
75 mm가 아니라 50 mm로 얕게 하고 Jg를 0.34 cm/s로 높인다. 그 결과 같은 동체에서도
유효 슬러리 체적은 0.794 m³로 러퍼의 0.778 m³보다 약간 크며, 최대 유량 실제 체류시간도
7.09분으로 러퍼의 6.53분보다 길다. 포수제 추가 투입은 실증 근거가 없어 적용하지 않았다.
locked-cycle 시험에서 추가 체류시간의 이득이 확인될 때만 예비 공간에 2차 스캐빈저를
직렬 증설한다.

스캐빈저 1기가 회로 Ag 회수율을 **84.2 % → 93.1 %** 로 올린다. 미광 손실은
940 → 411 g/t로 줄어든다.

> 이전 판에서는 러퍼 뱅크 2기 + 클리너 구성으로 스캐빈저를 두지 않았다.
> 러퍼 미광에 회수할 것이 거의 없다고 본 판단이 **과했다** — 실제로 계산해 보면
> 스캐빈저 단독 회수율이 65.5 %이고 회로 기여는 +8.9 %p다.

### 배치

클리너는 낮은 가대(y 0.46 m)에 놓아 **러퍼 정광이 자연유하**하게 했다.
러퍼·스캐빈저는 0.55 m 가대 위에 선다. 되돌리는 두 흐름(스캐빈저 정광, 클리너 미광)만
순환 펌프로 올린다. 스키드는 약 5.3 × 2.9 m.

입체 형상과 부품 구성은 [3D 조립·분해도](drawings/ag-flotation-3d.html) 참조 —
셀당 20개 부품(중공축·로터리 조인트 포함)에 배관·농축조·필터프레스 12개를 더해
분해해 볼 수 있다.

## 9. 약제 계통

**pH 조정제·황화제·억제제를 쓰지 않는다.** 남은 것은 세 가지뿐이다.

| 약제 | 역할 | 투입량 | 조제 | 펌프 (최대) | 투입 지점 |
|---|---|---|---|---|---|
| AEROPHINE 3418A | 포수제 | 300 g/t | 10 % | 1.47 L/h | CT-1 |
| AEROFLOAT 242 | 촉진제 | 300 g/t | 10 % | 1.47 L/h | CT-1 |
| MIBC | 기포제 | 30 ppm (물 기준) | 원액 | 0.25 L/h | **ES-1 급광** (청수) + **CT-1 보충수 몫 트림** |

**투입량 300 g/t 는 습식 분쇄 원료 기준이다.** [2] 에 따르면 건조 원료의 최적치는
150 g/t 였으나, 습식 분쇄물은 거품 형성이 부족해 2배가 필요했다. 실기는 습식
분쇄물을 그대로 쓰므로 300 g/t 가 설계값이다.

**기포제는 물 기준(ppm)으로 관리한다.** 거품 안정성은 수상 농도로 결정되기 때문이다.
7 wt% 운전에서는 t 당 환산 399 g/t 이지만, 30 wt% 로 올리면 t 당 소요량이 1/6 로
줄어든다 — 고농도 운전의 부수적 이득이다. MIBC 는 수용해도가 약 17 g/L 라 희석하면
정량펌프 유량이 20 L/h 까지 커지므로 **원액 투입**하고 검량통을 단다.

**기포제는 떨어진 EVA 분리(ES-1, §5.8)에서 먼저 쓰고, CT-1 에서 보충수 몫만 더한다.**
ES-1 급광에 넣은 MIBC 는 ES 미광의 물을 따라 부선조까지 간다. CT-1 보충수(공정수)는 그 몫이
없으므로 따로 넣는다 — 1안 최대 처리량에서는 합의 2 %(0.005 L/h)지만 평균 처리량에서는
보충수가 2.86 m³/h 로 커져 **42 %(0.106 L/h)** 가 된다. 공정수에 남은 MIBC 만큼 줄이며 거품
상태로 조정한다 (트림, FQ-109). 공정수는 ES 로 가지 않으므로 ES 의 MIBC 는 넣은 만큼만이다.
포수제·촉진제는 반드시 ES **뒤**(CT-1)에서 넣는다 — 앞에서 넣으면 은이 EVA 와 함께 떠 EVA
산물로 샌다. 회수 공정수를 ES 앞에 쓰지 않는 것도 같은 이유다 (§5.9).

잡아 bias 를 직접 연산·제어해야 한다. 기계식 셀의 액면 제어와는 성격이 다르다.

3. 계면 HH → 급광 정지
4. 정광 여과기 만액 → 급광 정지
5. 어트리션 급광 밀도 < 61 wt% → 경보 (스크러빙 불성립 — 바이패스 검토)

   인터록이 아니라 **운전 절차서로 강제**한다 (플러싱 없이 정지 시 경보 기록)

## 11. 시운전 및 성능 확인 계획

모델은 문헌값을 8 % 이내로 재현하지만, 문헌의 원료와 실제 원료는 다를 수 있다.

| 단계 | 시험 | 산출물 |
|---|---|---|
| 1 | 실제 급광 assay (ICP-MS + 파이어애세이 대조), TIMA 해리도 | `design_basis.CELL_FRACTION` 갱신 |
| 2 | 1 L 회분식, 정광 30초 간격 분취 (0.5·1·2·3·6 min) | 2속도 속도상수 재보정 |
| 3 | 약제 투입량 최적화 (75~600 g/t), **습식/건조 원료 비교** | 300 g/t 검증 |
| 3a | **PAS-1 파일럿 (§5.6)** — P-0A·P-0B(H₂ · 시운전)를 먼저, 그다음 P-0~P-6: EVA 박리 곡선, 시간 대조, 운전 변수, 라이닝 민감도 (AS-1 T-1·T-2·T-4) | E95 → AS-1 판정(그대로 / 모터 교체 / 셀 추가), 비에너지 설정값·미립 증가, 배기량 · H₂ 감소 속도 확정 |
| 3b | **S-1 · S-2 · S-1W · S-1H (§5.8)** — PAS-1 산물의 회분 EVA 부선 (기포제만), 크기별 회수, 회수수 · 20 wt% 비교 | t90 → ES 판정(그대로 / 셀 추가), 거품 Ag, 부착 효율 Ea, 물 계통 대안(W3 · W4) 판정 자료 |
| 3c | **연쇄 시험 C-1 (§5.8)** — PAS-1 → S-1 → 포수제 러퍼·클리너를 회수수로 이어 3~5 사이클 | 부착 EVA 가 은 부선에서 뜨는가 → 박리 목표 확정, 회수수 잔류 포수제 → 물 계통 확정 (§5.9) |
| 4 | **연속 파일럿 — 고체 농도 단계 상승 (7 → 15 → 30 wt%)** | 고농도 운전 가부 확정 → 동체 재산정 |
| 5 | bias 민감도 (Jb 0.1 ~ 0.4 cm/s) | 품위-회수율 균형점 확정 |
| 6 | 코드 재실행 | 갱신된 계산서 |
| 7 | 실기 72시간 연속 시운전 (0.3 / 0.4 / 0.5 t/h) | 성능 보증 |
| 7a | **AS-1 실기 확인 (§5.4 T-3)** — 급광·배출 부착 EVA 비교, 바이패스 교대 | 비에너지 설정값 확정, 존치 여부 결정 |
| 7b | **ES 실기 확인 (§5.8 S-3)** — 급광·미광·EVA 산물 채취 (수동 바이패스는 정광을 따로 받으며) | 부선 급광 자유 EVA ≤ 0.1 wt%, EVA 산물 Ag |

**4단계가 가장 중요하다.** 고체 농도 30 wt% 가 PV 원료로 확인되면 같은 Ø350 mm
동체로 2.5 t/h 가 나온다 — 설비를 5배 키운 것과 같다. 반대로 7 wt% 를 넘기지 못하면
물 회수 설비 부담이 그대로 남는다. **이 한 가지 시험이 설비 경제성을 좌우한다.**

### 성능 보증값 (제안)

| 항목 | 보증값 | 조건 |
|---|---|---|
| Ag 회수율 (계통 — EVA 산물 손실 포함) | ≥ 95 % | 급광 0.5 t/h, P80 66 µm, 7 wt% |
| 정광 Ag 품위 | ≥ 40 wt% | 동일 |
| 정광 mass pull | ≤ 2 % | 동일 |
| 미광 Ag 품위 | ≤ 300 g/t | 동일 |
| 가동률 | ≥ 95 % | 계획정비 제외 |

보증값을 계산값(계통 99.64 % — 부선 99.7 % 에서 EVA 산물로 새는 0.062 % 를 뺀 값)보다 낮게
잡은 것은 원료 변동과 상류 박리 품질 편차를 감안한 것이다. 회수율은 부선조만이 아니라 ES
까지 넣은 계통으로 잰다 — EVA 산물 Ag 를 빼먹으면 보증 시험이 계통 손실을 놓친다.

### 안정화 대기 시간

성능 측정은 기동 직후가 아니라 회로가 정상상태에 든 뒤 시작해야 한다.
2안 3단 회로의 기동 과도응답을 CSTR 연립 ODE 로 적분하면 (계산서 §8.2)
**회수율의 95 % 도달에 약 7분, 99 % 에 약 12분**이 걸린다 — 순환류(스캐빈저
정광·클리너 미광)가 안정되는 시간도 같은 규모다. 시험 프로토콜에는 여유를
실어 **기동 후 30분 대기**를 권고한다. 기포-입자 수력학 검산(계산서 §8.1)은
설계 속도상수가 Yoon-Luttrell 충돌 효율과 문헌 범위의 부착 효율(Ea 0.11~0.19)
로 재현됨을 확인했다.

기포·입자 애니메이션은 `pip install -e '.[simulation]'` 후
`python tools/flotation_sim.py fc201-simulation.mp4`로 재생성할 수 있다. 셀 치수,
기포 상승속도와 기동 곡선을 설계 코드에서 직접 읽는다. 다만 충돌·부착·탈착 확률은
시각화를 위한 경험계수이므로 이 도구는 **CFD/DEM 검증이 아니라 축약차수 교육용
모델**이다. 제작 승인에는 다상 CFD/입자 추적과 파일럿 시험이 별도로 필요하다.

## 12. 코드로 재계산하기

패키지가 `src/` 레이아웃이므로 설치 없이 실행할 때는 `PYTHONPATH=src` 를 붙인다
(`pip install -e .` 로 설치했다면 `flotation-design` 으로 바로 실행).

```bash
PYTHONPATH=src python -m flotation_design                               # 계산서 표준출력
PYTHONPATH=src python -m flotation_design -o docs/design-calculation.md # 파일로 저장
PYTHONPATH=src python -m flotation_design --peak-tph 0.6                # 처리량 변경
python -m unittest discover -s tests -t .                               # 검증 (1330건)
```

설계 전제는 모두 `src/flotation_design/design_basis.py` 한 곳에, 문헌 실증값은
`src/flotation_design/references.py` 에 있다. 시험 결과가 나오면 전자를 갱신하고
재실행하면 동체 치수부터 약제 소요량까지 일관되게 다시 계산되며,
`tests/test_references.py` 가 문헌과의 정합성을 계속 지켜준다.
